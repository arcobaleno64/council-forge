新增兩個函數（在 `normalize_assurance_level` 之後）：

**`validate_assurance_level_strict(value: str) -> str`**
- 空值 → raise ValueError（explicit error: assurance_level required）
- 非法值（含 "high"）→ raise ValueError（explicit error: not in allowed vocabulary）
