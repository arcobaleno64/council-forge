## Summary Of Changes

### guard_status_validator.py (+ template mirror)

Added four new module-level constants:
- `_STRICT_FLOOR_COMMIT_RE` — matches git commit hashes (7–40 hex chars)
- `_STRICT_FLOOR_URL_RE` — matches `https?://` URLs
- `_STRICT_FLOOR_CMD_RE` — matches backtick-quoted commands
- `_STRICT_FLOOR_STATUS_RE` — matches `[OK]`, `[PASS]`, `[FAIL]` output markers
- `_STRICT_FLOOR_FILEPATH_RE` — matches `artifacts/...` file path references
- `_STRICT_FLOOR_VALID_RESULTS` — frozenset `{verified, deferred, unverifiable}`

Added two new functions:

**`_check_strict_verify_floor(verify_path, task_id) -> List[str]`**
- Checks `## Build Guarantee` section: present, non-empty, has concrete evidence
  (commit hash / URL / backtick command / [OK] marker / artifacts/ path)
- Checks `## Evidence Refs` section: present, not "None"/"N/A"
- Checks all checklist items: `result:` field present and in valid set

**`run_verify_floor_enforce(repo_root) -> int`**
- Loads `verify-floor-baseline.v3.4.json`
- Scans `artifacts/verify/TASK-*.verify.md`
- Classifies each into: baseline_unchanged / historical_exception / post_baseline_new / post_baseline_modified
- Runs `_check_strict_verify_floor` on all post-baseline targets
- Prints categorized report with counts; exits 1 on any strict failure

**Parser changes:**
- `--task-id`: `required=True` → `required=False, default=None`
- Added `--verify-floor-enforce` (store_true)
- Added `--root` / `dest=repo_root` (default=None)

**`main()` changes:**
- Early `if args.verify_floor_enforce:` → `run_verify_floor_enforce(repo_root)`; returns before task-id checks
- Early `if args.task_id is None:` guard for non-enforce mode
