   - Updated marker check at validate_markdown_artifact to use `_required_markers_missing`.
   - Updated `Ready For Coding` regex check to skip when `_is_v2_plan(text)` is true.
   - Updated `Verification Obligations` mvp/production check to skip when `_is_v2_plan(text)` is true.
   - Updated `validate_decision_artifact`: read `decision_class` from H2 first, then frontmatter; accept any value matching the canonical 5 OR `is_governance_decision_class`; relax Affected Gate format check for governance class; relax Expiry timestamp check for governance class; allow `## Evidence Refs` or `## Follow Up` to substitute for `## Linked Artifacts` for governance class.

   - Replaced `parse_verify_checklist_items` to split on `^- \[[ x]\]\s+\S+:` line-anchored item-start markers, with v1 blank-line-boundary preserved as a fallback when no AC-N start is present.
   - Replaced `parse_structured_checklist_fields` to recognise `- [x] AC-N: criterion text` inline-criterion form (records `__inline_criterion__: true`), and to split single-line multi-fields like `- result: x, reviewer: y, timestamp: z` into separate fields by recognising only POLICY_STRUCTURED_CHECKLIST_FIELDS keys.
