## Summary Of Changes

**Bug A fix（雙 wrapper 同步）**：

1. 新增 `Get-LifecycleUntrackedSnapshot` helper：列舉 7 lifecycle dirs（`Get-LifecyclePathPrefixes` return）內既存 untracked 檔（`git ls-files --others --exclude-standard -- <prefix>...`）；對每 path 跑 `git hash-object -w <path>` 寫入 .git/objects 並取 SHA-1；return hashtable `@{ <forward-slash-path> = <sha1-hex>; ... }`。`-w` flag 為關鍵：使 `Restore-PostDispatchDelta` 可用 `git cat-file blob <hash>` 取回 byte-exact 原內容。Return 採 `, $snapshot` unary comma 防 PowerShell function return 之 hashtable 0/1-element unrolling。
2. `Save-PreDispatchState` 重構：return 改為 `[PSCustomObject]@{ StashRef = ...; LifecycleUntrackedSnapshot = ... }`（避免 hashtable 與 function output stream 之 array-mixing quirk，per R1 mitigation）；3 處 return paths（無 changes / 無 stash entry / 正常）皆改 PSCustomObject；既有 stash 邏輯保留；既有 stash msg 字面值 `TASK-1057 pre-dispatch <ts>` 保留（PR-029 anchor）；snapshot capture 在 stash 之前執行。

4. post-dispatch guard 之 `$violations` 計算後過濾：對每 violation P，若 `$lifecycleSnapshot.ContainsKey($P)` 且 post-dispatch `git hash-object $P`（不加 `-w`，避免再次污染 .git/objects）等於 snapshot value → 從 `$violations` 移除（user pre-existing untracked，未變動）；console 印 `[GUARD] Lifecycle pre-existing untracked (unchanged): <P>`；hash 變動或 path ∉ snapshot 則保留為 violation。
