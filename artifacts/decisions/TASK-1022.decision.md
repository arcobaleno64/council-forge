## Reasoning

1. **Design-only 邊界**：TASK-1022 的唯一目的是建立可供 Prompt 6e 使用的 adversarial case library。執行 case 需要 run_red_team_suite harness（Prompt 6c 建立），目前尚不存在；設計先於工具，符合 artifact-first 原則。

2. **不重複 unit tests**：Prompt 2 unit tests 已覆蓋 classify_path + resolve_identity 的直接呼叫行為。Adversarial cases 必須測試**跨 artifact 層、多步驟、語意操縱**的攻擊面，而非重新測試相同輸入/輸出對。

3. **Prompt 6e 是唯一執行授權**：unit-test duplicate cases 不計入 adversarial assurance，此規則必須在 design 階段就顯式記錄，讓 Prompt 6e 有明確依據去識別並排除重複。

4. **Template/scripts 不觸碰**：TASK-1022 是 design-only；任何對 guard_contract_validator.py / workflow_constants.py / agent_identity.py 的改動都超出本任務 scope，且會破壞 TASK-1007 已通過的 contract validation。
