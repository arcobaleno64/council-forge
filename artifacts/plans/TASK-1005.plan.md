## Risks

R1
- Risk: 建立 artifacts 時誤修改授權範圍外之檔案（如 docs/ 或其他 task 之 artifacts），致 git status scope check 失敗
- Trigger: 在同一 session 中對 docs 或 other-task artifacts 發出 Write / Edit 呼叫
- Detection: Phase 5 之 `git status --short` 列出非六檔路徑之 new/modified file
- Mitigation: 每次 Write / Edit 呼叫前確認路徑屬於授權六檔；verify artifact §AC-3 之 scope compliance 為最終關卡
- Severity: blocking

R2
- Risk: artifact metadata 欄位不符 docs/artifact_schema.md schema（如 timestamp 缺 +08:00、Status 值不合法），致後續 guard_status_validator.py 報 schema violation
- Trigger: 建立 artifact 時遺漏 PDCA Stage 欄位、或 timestamp 格式不完整
- Detection: guard_status_validator.py 報 metadata schema error；verify artifact §AC-1 evidence 顯示欄位不齊
- Mitigation: 每個 artifact 建立後即核對 §5.1 / §5.3 / §5.4 / §5.6 / §5.8 之必填欄位；timestamp 一律 ISO 8601 +08:00；verify checklist 採單行欄位格式（無多行 block）
- Severity: blocking

R3
- Risk: scope 蔓延至 Prompt 0a（TASK-1021）或 runtime code artifacts，致 TASK-1005 授權或預執行後續 prompt 保留之工作
- Trigger: 任何 Write / Edit 呼叫發向 TASK-1021 路徑、runtime validator、docs、template、.github 或 RACI 等非授權範圍之檔案
- Detection: verify artifact §AC-3 git status 列出非 TASK-1005 路徑；或 decision artifact 缺少 Non-authorization 顯式聲明
- Mitigation: decision artifact 含明確 Non-authorization 顯式聲明；code artifact 設 DOCS_ONLY / GOVERNANCE_RECONCILIATION_STUB 且 Files Changed = None；所有 write 前確認目標路徑
- Severity: blocking
