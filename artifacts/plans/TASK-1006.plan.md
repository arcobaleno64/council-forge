1. **TASK-1020.decision.md Affected Gate 格式修復**：
   - 舊值：`Gate_B（Planning gate；本 decision 處理 plan 層級之 supersession）`

2. **run_red_team_suite.py RT-LIVE-964 移除**：
   - 移除 `case_live_964()` function（14 行）。
   - 移除 LIVE_CASES 中的 `CaseDefinition("RT-LIVE-964", ...)` registration（1 行）。
   - 理由：RT-LIVE-964 依賴 TASK-964 legacy evidence（right-answer-for-wrong-reason；非 canonical Codex CLI proof）；v3.4 plan §4.4 規定 TASK-964 legacy evidence 不得作為 canonical evidence。source/template drift 僅能以消除 source side 解決（不得同步到 template）。Production canonical drill 由 TASK-1010 負責。

3. **threat-inventory.json JSON 損毀修復**：
   - 問題：兩個 JSON object 直接相接（第一個 object 結束後接第二個 `{`）。
   - 修復：使用 `json.JSONDecoder().raw_decode()` 解析第一個有效 object，截斷餘下拼接部分，以 `json.dump(..., indent=2)` 重寫。
   - 保留第一個 object（含 `findings` array FIND-01~FIND-12、`threats` array with `tier` field）；移除第二個 object（舊格式，無 `findings`，無 `tier`，有 `affected_flows`，與第一個 object 有重複 threat IDs）。
   - 修復後：json.loads 可正常解析（findings: 12, threats: 29）。

4. **threat-findings-pending-update.v3.4.json FIND-18 entry**：
   - 加入 FIND-18（source/template contract drift）entry，proposed_status = "In-Progress"。
