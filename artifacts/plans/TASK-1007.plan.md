## Risks

- R1: Risk: classify_path 的 prefix rule 順序錯誤，導致 artifacts/tasks/ 被錯誤分類為 artifacts/ 或 task。
  Trigger: 前置較長 prefix 放在較短 prefix 之後。
  Detection: AC-3（docs/ 分類為 workflow_contract_docs），AC-4（artifacts/code/ 分類為 code）；逐路徑 trace。
  Mitigation: _PATH_PREFIX_RULES 已按精確度順序排列；artifacts/ 子路徑各有專屬 prefix。
  Severity: blocking

- R2: Risk: EXACT_SYNC_FILES 加入 agent_identity.py 後，template 未同步，guard_contract_validator 報 drift。
  Trigger: 只建立 source 版 agent_identity.py，未 cp 到 template。
  Detection: guard_contract_validator 執行結果。
  Mitigation: cp source → template 三個檔案後立即執行 guard_contract_validator；確認 [OK]。
  Severity: blocking

- R3: Risk: _run_raci_audit_v2 中 --fix check 在 agent resolution 之前執行，改變 exit code 語意。
  Trigger: --fix 同時使用 unknown agent → 應回傳 exit 2（RACI_FIX_REJECTED）或 exit 2（UNKNOWN_IDENTITY）？
  Detection: AC-6 測試 --fix rejection；設計選擇 --fix 優先（先 check fix，再 check agent）。
  Mitigation: 明確定義 --fix 為最高優先 rejection，在 agent resolve 前 check；與 v3.4 plan §4.2 "--fix rejection" 要求一致。
  Severity: non-blocking

- R4: Risk: validate_raci_hybrid_sync 仍使用舊 RACI_MATRIX，可能與 RACI_MATRIX_V2 語意不一致。
  Trigger: RACI_MATRIX 含舊 category 名稱（"code (實檔修改)"、"Remember Capture draft"）；v2 使用 path categories。
  Detection: guard_contract_validator --root . 執行結果（hybrid sync check）。
  Mitigation: RACI_MATRIX（v1）保留不變，由 validate_raci_hybrid_sync 繼續使用；RACI_MATRIX_V2 只用於 _run_raci_audit_v2；兩者互不干擾。
  Severity: non-blocking
