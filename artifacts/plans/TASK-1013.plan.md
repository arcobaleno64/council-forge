## Risks

- R1: Risk: `init_streams()` 中 hasattr/getattr 條件與原始邏輯不一致，導致 Windows 上 encoding fix 失效。
  Trigger: 條件判斷不夠精確，符合條件時不執行 stream 替換。
  Detection: AC-4（CLI 行為確認）；在 encoding != utf-8 環境測試。
  Mitigation: 保持與原始邏輯等效：`hasattr(out, 'buffer') and getattr(out, 'encoding', 'utf-8') != 'utf-8'`；在非 UTF-8 環境下才替換。
  Severity: non-blocking

- R2: Risk: template sync 後 guard_contract_validator 因 validate_context_stack.py 不在 EXACT_SYNC_FILES 而仍報 [OK]，但 template 實際未更新。
  Trigger: 手動 sync 失誤。
  Detection: AC-7（guard_contract_validator --root .）；AC-5（diff source vs template）。
  Mitigation: 修改 source 後立即以 Python read+write 精確同步 template；再執行 guard_contract_validator 確認。
  Severity: non-blocking

- R3: Risk: import-only test 在 Windows 環境因 encoding 差異產生 side effect。
  Trigger: sys.stdout.encoding != "utf-8" → 觸發替換（修正前）。
  Detection: AC-1（import test 無輸出）；AC-2（git status 相同）。
  Mitigation: 修正後模組層無任何條件判斷，import 絕對無 stream mutation。
  Severity: blocking

- R4: Risk: TASK-1013.verify.md 被 verify-floor strict 要求拒絕（缺 decision_ref 或 reason_code）。
  Trigger: deferred items 未附 decision_ref。
  Detection: guard_status_validator --verify-floor-dry-run。

  Severity: blocking
