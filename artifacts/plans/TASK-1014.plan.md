## Risks

- R1: Risk: timeout sentinel returncode 與某 test case 的 expected_exit_code 意外相等，導致 timeout 被誤判為 pass。
  Trigger: 若 TIMEOUT_RETURNCODE 選用 0 或 1 等常見 exit code。
  Detection: smoke test 驗證 timeout returncode = -9999；build_case_result 自然排除（-9999 != 0 or 1）。
  Mitigation: 使用 -9999 作為 sentinel，與 0/1/-1 完全不同。
  Severity: blocking

- R2: Risk: Popen.communicate(timeout=...) 後 proc.kill() 在 Windows 不立即生效，子 process 殘留。
  Trigger: TerminateProcess 系統呼叫非同步情況。
  Detection: smoke test 確認 timeout 後 returncode = TIMEOUT_RETURNCODE 且 process 不殘留。
  Mitigation: proc.kill() 後再次 proc.communicate() drain buffer（Python 官方文件標準 idiom）。
  Severity: blocking

- R3: Risk: _cap_output 截斷含多 byte UTF-8 字元時，截斷邊界產生非法 byte sequence。
  Trigger: 截斷邊界落在多位元組字元中間。
  Detection: decode errors="replace" 安全處理。
  Mitigation: 截斷後以 errors="replace" decode，附加截斷標記。
  Severity: non-blocking

- R4: Risk: run_git_command 未明確傳入 timeout，git fixture 操作無保護。
  Trigger: 只改 run_command 簽名但 run_git_command 未更新。
  Detection: 確認 run_git_command 呼叫有 timeout=SUBPROCESS_GIT_TIMEOUT。
  Mitigation: 明確更新 run_git_command 傳入 SUBPROCESS_GIT_TIMEOUT。
  Severity: non-blocking
