## Risks

R1
- Risk: 對 root 與 template script 的量測中，`grep` 或 `wc -l` 之計算誤差（如缺末行 newline、混合 CRLF）導致 LOC / function_count 與 `git diff` 之實際結果不一致；後續 TASK-1025 QC-SYNC-001 可能因 normalization 假設不同而把 in_sync 對誤判為 drift
- Trigger: 倉內某 .py 檔以 CRLF 結尾（Windows 環境），`wc -l` 對缺末行 newline 之檔少計一行；或 `grep` 對 `^def ` 之 anchor 在 CRLF 下行為與 LF 不同
- Detection: TASK-1025 實作 QC-SYNC-001 時，對相同 `in_sync` pair 重做 sha256 出現差異；或 baseline 量測之 sha256 與 git internal blob hash 對照不一致
- Mitigation: baseline JSON 之 `metrics_methodology` 顯式記載 LOC 與 function_count 之計法（`wc -l`、`grep -cE '^[[:space:]]*(def |async def )'`、原 bytes sha256）；TASK-1025 須以同樣方法重算驗證一致性，或選擇換用 AST-based count 並在 decision artifact 記錄 method change
- Severity: non-blocking

R2
- Risk: 在 Phase 2 量測過程中誤觸 import 或執行 `python -c "..."` 致 `__pycache__` 被建立；commit 階段意外把 cache file 一起 stage / commit，污染 repo 並違反 v3.5 plan §3.2 「Forbidden during preflight」與 TASK-1024 §Constraints 之 inventory-only 規約
- Trigger: 為了拿 docstring / argparse help text 而誤跑 `python -m guard_status_validator --help` 或類似指令；或某 ripgrep 替代手段引入 import
- Detection: Phase 4 `git status --short` 出現 `__pycache__/` 路徑；或 `git diff --cached --name-only` 含非允許清單之檔
- Mitigation: 量測完全以 `wc` / `grep` / `sha256sum` / `ripgrep` 完成，**不**執行任一 `python` 指令；commit 前以 `git diff --cached --name-only` 嚴格比對六項允許清單；若 staged 多出 cache file，立即 `git restore --staged` 並 `rm -rf __pycache__`，於 verify artifact 標記 R2 觸發
- Severity: blocking

R3
- Risk: existing drift（QB-DRIFT-0001..0003）被誤識為 TASK-1024 acceptance failure，導致 status 被誤標 `blocked` 且 commit 被誤阻；或反向地，drift 被悄悄 normalize（如 `git checkout`、CRLF 重寫）後 sha256 對齊，掩蓋真實 baseline 狀態，破壞 TASK-1025 enforcement input
- Trigger: 撰寫 verify artifact 時把 `existing_drift_entries.length > 0` 等價於 `Pass Fail Result: fail`；或對 `template/artifacts/scripts/test_guard_units.py` 執行任何 normalize 操作
- Detection: verify artifact 之 `Pass Fail Result` 與 baseline JSON 之 drift 數量產生 false 對應；或 `git diff HEAD -- template/ artifacts/scripts/` 含非預期變動
- Mitigation: task §Acceptance Criteria AC-6 顯式聲明「existing drift 已記錄但**未** remediated」；plan §Scope 與 decision artifact 顯式聲明「inventory-only, drift is baseline state」；Phase 4 強制 `git diff HEAD -- artifacts/scripts/ template/` 應為 0 diff；任一 source/template paired file 變動即立即 `git restore` 並 abort
- Severity: blocking

R4
- Risk: TASK-1024 lifecycle 過程中無意建立 TASK-1025 / 1026 / 1027 之任一 artifact（如「順手把 prompt 1 的 task draft 寫了」），違反 non-authorization 條款
- Trigger: 撰寫 plan §Scope 描述 TASK-1025 enforcement 細節時，誤把段落內容存入 `artifacts/tasks/TASK-1025.task.md`
- Detection: Phase 4 `artifacts/{tasks,plans,decisions,verify,status}/TASK-102{5,6,7}.*` glob 結果非 0 hits
- Mitigation: 所有 TASK-1025+ 描述以「章節文字」形式存於本 plan / decision / verify；Phase 4 嚴格 glob；commit 前 `git diff --cached --name-only` 比對六項允許清單
- Severity: blocking
