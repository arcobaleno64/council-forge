## Approach

1. **Lifecycle artifacts** — write TASK-1037 task / plan / decision / verify-stub /
   status-stub. The verify and status are finalised after the harness run.

2. **Case manifest** — author `artifacts/verify/TASK-1037/golden-cli-case-manifest.json`
   covering nine required case groups (GCLI-PRECOMMIT-DEFAULT / EVREF / FAILCLOSED /
   LIFECYCLE + GCLI-QUALITY-SYNC / SCHEMA / IMPORT / GOLDEN / RUFF-ADVISORY).

3. **Harness** — author `artifacts/verify/TASK-1037/run_golden_cli_coverage.py`
   (Python standard library only). The harness:
   - Sets `sys.dont_write_bytecode = True` at import top.
   - Builds the controlled fixture tree under
     `artifacts/verify/TASK-1037/fixtures/` deterministically.
   - Copies the production PCACC and quality runners byte-for-byte into each
     fixture repo (so each runner's `SCRIPT_PATH.parents` resolves to the
     fixture repo root, not the live repo root).
   - Invokes the fixture-local runner copy via
     `python -B <runner> --task ... --policy ... [--evidence-ref-policy ...]
     --self-check` with subprocess env containing
     `PYTHONDONTWRITEBYTECODE=1`, `PYTHONNOUSERSITE=1`, `PYTHONUTF8=1`.
   - Captures `(exit_code, stdout, stderr)` per case and asserts the contract:
     `exit_code` literal, JSON parse on stdout, locked field subset, locked
     reason_code (literal or prefix), `stderr` empty unless explicitly
     justified.
   - Sweeps for `__pycache__` / `*.pyc` under fixture root and the harness
     directory; reports any hits.
   - Computes sha256 prefixes of nine production preservation targets
     against the TASK-1036 baseline.
   - Writes `artifacts/verify/TASK-1037/golden-cli-coverage-result.json`.

4. **Run harness** — execute the harness once. If `overall_status != pass`,
   stop and resolve before commit.

5. **Verify + status** — finalise `artifacts/verify/TASK-1037.verify.md`
   (30 AC checklist + Build Guarantee) and `artifacts/status/TASK-1037.status.json`
   (state=done only when result JSON overall_status=pass).

6. **Commit** — stage exactly the TASK-1037 authorized files; commit with
   message `TASK-1037 implement golden cli coverage`; report commit hash.

## Risks

### R1: Fixture repo root detection drifts to live repo root

Both production runners use `Path(__file__).resolve().parents` to detect
repo root by sentinel (`consilium-fabri-governance-repair-plan-v3.5.md`).
If the harness invokes the live runner directly, it will detect the live
repo root and consume live policies / baselines, defeating fixture isolation.

**Mitigation**: For every case, the harness copies the production runner
byte-for-byte into the fixture repo at the same relative path
(`artifacts/scripts/run_precommit_check.py` or `run_quality_gates.py`)
and invokes the **fixture-local copy**. This makes
`SCRIPT_PATH.parents` resolve to the fixture root, not the live root.

### R2: Subprocess emits __pycache__ under fixture or live tree

Without explicit suppression, Python may write `.pyc` files when invoking
the runner copy.

**Mitigation**: Harness sets `sys.dont_write_bytecode = True` at import top;
subprocess env contains `PYTHONDONTWRITEBYTECODE=1`; subprocess args use
`python -B`. Post-run sweep over `artifacts/verify/TASK-1037/` and the
project root reports zero `__pycache__` / `*.pyc` attributable to this task.

### R3: TASK-1030 NEG-002 / NEG-003 backward compat anchor drift

If the harness's expected reason_code for default-mode NEG-002 / NEG-003
differs even by a single character from TASK-1030 actual_reason_code, the
contract is broken even though the harness reports pass.

**Mitigation**: Harness asserts byte-identical literals
`malformed_refs:garbage_token_not_a_known_prefix` (NEG-002) and
`evidence_refs_section_empty` (NEG-003), sourced from
`artifacts/verify/TASK-1030/pcacc-negative-test-result.json` per TASK-1035
RTX-005 evidence.

### R4: Quality runner Pass-2 discover_current_pairs pollutes case-specific reason_code

Quality runner walks `artifacts/scripts/*.py` and `template/artifacts/scripts/*.py`
to detect post-baseline new pairs. The fixture-local runner copy itself
will be detected as a new pair.

**Mitigation**: For each Quality case, the harness asserts the QC-SYNC-001
check whose `target` matches the case-specific source path (case payload),
not the runner self-pair. The runner self-pair is expected to pass with
`reason_code=post_baseline_new_pair_in_sync` (since both copies are
byte-identical).

### R5: Quality SCHEMA gate uses fixed paths under repo root

Quality runner's `REQUIRED_JSON_TARGETS` is hardcoded to read
`governance-repair-manifest.v3.5.json`,
`artifacts/status/TASK-{1023,1024,1025}.status.json`,
`artifacts/governance/quality-baseline.v3.5.json`, and
`artifacts/governance/quality-gate-policy.v3.5.json`. The schema gate
reads these from `repo_root` regardless of `--baseline` / `--policy`.

**Mitigation**: For SCHEMA cases, the fixture repo includes deterministic
stubs for all six required JSON targets at the canonical paths. The
SCHEMA-002 (schema_version_mismatch) case mutates the
`artifacts/governance/quality-baseline.v3.5.json` schema_version to
trigger fail; `--baseline` is not used to drive SCHEMA outcome.

### R6: Production runner sha drift between harness write and Codex verification

If the harness reads the production runner at run time and Codex re-reads
the production runner during post-commit verification, sha must remain
exactly `4dbb8a219093cc12` (PCACC) and `456b8328482b18a5` (quality).

**Mitigation**: Harness writes the production preservation block in
`golden-cli-coverage-result.json`, reporting both the live sha (read at
harness time) and the expected baseline sha (TASK-1036 record). Codex can
re-verify post-commit; this lifecycle does not edit the runners.

### R7: TASK-1038+ lifecycle artifact accidentally created

A typo or path slip could create `artifacts/{tasks,plans,decisions,verify,status}/TASK-1038*`.

**Mitigation**: Pre-commit `git diff --cached --name-only` is inspected
against the TASK-1037 allowed list. If any TASK-1038+ path appears,
commit is aborted.

### R8: Fixture writes leak outside fixtures/ directory

If a relative path slip writes outside `artifacts/verify/TASK-1037/fixtures/`,
the controlled fixture envelope is broken.

**Mitigation**: Harness `write_file()` validates that the resolved target
path is under `FIXTURE_ROOT` for fixture content and under `TASK_DIR`
for harness output. Any slip raises before write.

## Premortem

### R1 (fixture repo detection)

Cause: Live runner's `SCRIPT_PATH` resolves to live repo root, ignoring
the fixture tree we built.

Mitigation: per-case fixture-local runner copy; harness invokes the copy.

Detection: harness asserts every `--policy` arg points at fixture-local
path; production preservation block re-reads the live runner sha after
the run and compares to TASK-1036 baseline.

### R2 (cache pollution)

Cause: Default Python writes `.pyc` to `__pycache__/` when importing
modules.

Mitigation: `sys.dont_write_bytecode = True`; subprocess `python -B` +
`PYTHONDONTWRITEBYTECODE=1`.

Detection: post-run sweep over `artifacts/verify/TASK-1037/` and project
root; result JSON `cache_audit.pycache_created` must be `false`.

### R3 (NEG-002 / NEG-003 anchor drift)

Cause: Harness writes the wrong literal in expected_reason_code.

Mitigation: literals are constants in the harness; harness compares
byte-identical against TASK-1030 NEG-002 / NEG-003 actual_reason_code.

Detection: case status `pass=false` if anchor drifts; result JSON
`overall_status=fail`.

### R4 (Pass-2 reason_code pollution)

Cause: Asserting on the wrong QC-SYNC-001 check (e.g. the runner self-pair).

Mitigation: assertion targets `(check.gate_id == "QC-SYNC-001" and
check.target == case_target_path)`.

Detection: harness explicit selection raises StopIteration if the
expected target check is missing.

## Build Guarantee

1. **Result JSON pass**: harness execution produces
   `artifacts/verify/TASK-1037/golden-cli-coverage-result.json` with

2. **Production preservation**: harness records sha256 prefix of nine

If either condition is violated, the harness sets `overall_status=fail` and
the commit must not occur.
