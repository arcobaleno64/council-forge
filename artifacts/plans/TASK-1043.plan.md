## Risks

### R1: Snapshot drifts from TASK-1042 evidence

A copy-paste error could record a wrong golden CLI count, a
wrong implementation boolean, or a wrong cache audit field
value, divorcing the snapshot from the underlying evidence.

- **Risk**: snapshot index reports `passed_cases=24` when the underlying result reports `passed_cases=25`.
- **Trigger**: hand-copying numbers without re-reading the source JSON.
- **Detection**: TASK-1043 inspection evidence cross-checks each represented value against the source artifact; TASK-1043 verify markdown enumerates the source artifact for each AC.
- **Mitigation**: every represented value is sourced from a single authoritative file (the TASK-1042 evidence JSON); the inspection JSON references the source artifact in `evidence_ref` for each check.
- **Severity**: blocking

### R2: Accidental mutation of TASK-1042 evidence

Editing `artifacts/verify/TASK-1042/...` to “tidy up” fields
during snapshot authoring would lift the closure boundary.

- **Risk**: a TASK-1042 evidence file is silently modified while authoring TASK-1043.
- **Trigger**: opening a TASK-1042 evidence JSON for editing rather than reading.
- **Detection**: pre-commit `git diff --cached --name-only` and `git status --short` confirm the staged set is limited to the eight TASK-1043 authorized files.
- **Mitigation**: TASK-1042 evidence is read-only during TASK-1043 authoring; `git add` is performed by exact path; staging set is enumerated before commit.
- **Severity**: blocking

### R3: Commit noise leaks unrelated working-tree state

`.obsidian/`, `.omc/`, `.tmp/`, `.pytest-basetemp/`,
`__pycache__/` are known non-blocking local noise. A wide
`git add` would stage them.

- **Risk**: unrelated state is committed alongside TASK-1043 artifacts.
- **Trigger**: `git add -A` or `git add .`.
- **Detection**: pre-commit `git diff --cached --name-only` is compared against the TASK-1043 allowed list; staging is performed by exact path.
- **Mitigation**: stage by exact paths; final pre-commit check enumerates the staged set.
- **Severity**: non-blocking
