## Risks

- R1: Risk: Bulk text replacement accidentally rewrites historical artifacts (TASK-952..TASK-1045) that mention "Consilium Fabri" / "consilium-fabri" as historical record.
  Trigger: rewrite script's path whitelist mistakenly includes a TASK-* lifecycle directory.
  Detection: `git diff f086552 -- artifacts/{tasks,research,plans,decisions,code,verify,status,improvement,governance,red_team}/TASK-*` output empty after rewrite.
  Mitigation: Whitelist is path-explicit (no glob into `artifacts/...TASK-*`); script asserts that no path matching the historical regex is ever opened for write; SHA-256 comparison before / after on a representative TASK-1043 file as a canary.
  Severity: blocking

- R2: Risk: Sentinel rename (`.consilium-source-repo` → `.council-forge-source-repo`) breaks `guard_contract_validator.py` source-mode detection if any reference is missed.
  Trigger: validator hardcodes the old filename in more than one location and one is missed during rewrite.
  Detection: post-rewrite `guard_contract_validator.py` exits non-zero or reports source-mode misclassification.
  Mitigation: grep entire repo for the literal string `.consilium-source-repo` before declaring rewrite complete; verify both root and template mirror reflect new name; run validator end-to-end as confirmation.
  Severity: blocking

- R3: Risk: Downstream terminal repos that already cloned via the old `template/` carry a hard-coded reference to `.consilium-source-repo` filename in their `guard_contract_validator.py` and become incompatible with future template syncs.
  Trigger: a future downstream repo is cloned and run after this rename without sync.
  Detection: downstream `guard_contract_validator.py --check-readme` may fail with sentinel-related error.
  Mitigation: this task targets the source-template repo only; downstream repos must sync the renamed validator + sentinel together. Document in TASK-1046.improvement.md as a forward-compatibility note.
  Severity: non-blocking

- R4: Risk: `prompt_regression_cases.json` contains hard-coded fixture content that references the literal string `Consilium Fabri` or `consilium-fabri` and a regression case fails after rewrite.
  Trigger: a drill case's expected text contains the old name.
  Detection: `prompt_regression_validator.py --root .` reports a new failure.
  Mitigation: include `prompt_regression_cases.json` (root + template) in the rewrite whitelist; rerun the suite after rewrite; if a case still fails, inspect and decide whether to update the case content or revert that case's name reference (cases that reference "Consilium Fabri" as the project name should update; cases that reference an old artifact filename should keep the historical reference).
  Severity: non-blocking

- R5: Risk: GitHub `gh repo rename` requires write authority on the repo and may fail under SAML SSO restrictions or org policies.
  Trigger: SSO not authorised for the gh CLI session, or the repo is in an org that disables rename.
  Detection: `gh repo rename` returns non-zero with a permissions error.
  Mitigation: the rename is intended to be performed by the owner (`arcobaleno64`); if `gh` fails, fall back to GitHub web UI Settings → Repository name. After rename succeeds, `git remote set-url` is mechanical.
  Severity: non-blocking

- R6: Risk: Historical permalinks in research artifacts (e.g. `https://github.com/arcobaleno64/consilium-fabri/blob/0a6fb6f/...`) become unreachable.
  Trigger: GitHub redirect lapses (officially "old name → new name" redirect persists indefinitely as long as the new name resolves and the old name is not reused; permalinks pinned to a SHA survive).
  Detection: a future user clicks the URL and reaches a 404.
  Mitigation: GitHub's repo rename redirect is durable for as long as the new repo exists and the old slug remains unused; permalinks pinned to a commit SHA stay valid via the redirect. Document this expectation in TASK-1046.improvement.md.
  Severity: non-blocking

- R7: Risk: README badge URLs or asset URLs reference `consilium-fabri` in image source paths.
  Trigger: a `<img src="https://...consilium-fabri...">` is present in README.
  Detection: visual review post-rewrite + curl check.
  Mitigation: rewrite script handles all `consilium-fabri` substring occurrences; manual scan of README post-rewrite for any non-rewritten URL.
  Severity: non-blocking
