## Risks

R1
- Risk: SKILL.md 內容含外部 Chat 不可執行之強制 CLI 指引（如「跑 python ...」），致該 Skill 在 ChatGPT / Claude Chat 環境失效，違 CI-5。
- Trigger: instruction 段落寫「執行 `python artifacts/scripts/discover_templates.py --scale ...`」而未標 Optional + 未提供 markdown table fallback；user 在外部 Chat 跑時 stuck。
- Detection: SKILL.md 全文 grep `python ` / `pip ` / `npm ` 等 CLI keyword，逐一檢核是否位於 Optional 段或 markdown table 上下文。
- Mitigation: 5-stage flow 全為 markdown 互動（純 LLM 解讀）；任何 CLI 動作明標「Optional: 若已有 council-forge clone」並提供 markdown table fallback；本批 Phase 4 之 13 範本表格內嵌（不依賴 CLI 動態輸出）。
- Severity: blocking

R2
- Risk: SKILL.md frontmatter 鍵名與既有 8 skills 漂移（如發明 `applicable_scale` 等新 key），致 skill discovery / 既有 Anthropic Skill 規範掃描失敗。
- Trigger: 寫 frontmatter 時憑記憶寫 `applicable_scale: standard` 等 TASK-1050 之 docs/templates 用法之 keys；Anthropic skill 規範可能不接受。
- Detection: 對既有 8 個 SKILL.md 之 frontmatter 結構 grep 比對；frontmatter 解析後欄位集合 ⊆ 既有 8 skills 之並集。
- Mitigation: 開檔前 cat 一個既有 skill（quality-playbook）frontmatter；採同樣 key 命名（name / description / license / metadata.version）；不發明新 key；TASK-1050 之 `applicable_scale` 屬 docs/templates 範本機制，與 .github/skills 不同層，不混用。
- Severity: non-blocking

R3
- Risk: SKILL.md 內容與 BOOTSTRAP_PROMPT.md 段落字面值漂移；後續修 BOOTSTRAP_PROMPT.md 但忘改 SKILL.md，user 收到過期版本。
- Trigger: SKILL.md Stage 5 複製 BOOTSTRAP_PROMPT.md 段落 verbatim 文字（違 CI-3）；BOOTSTRAP_PROMPT.md 修改後此 SKILL.md 未同步。
- Detection: SKILL.md 與 BOOTSTRAP_PROMPT.md 之段落 git diff 比對；若有重複塊（行數 ≥10 連續匹配），視為 violation。
- Mitigation: SKILL.md Stage 5 採「dispatch + 教學 placeholder 替換」風格——明確聲明「以 BOOTSTRAP_PROMPT.md 為單一來源；本檔僅指引使用者依 5-stage 結果替換 placeholder」；不複製段落字面值；輸出範本以 outline + 替換步驟形式呈現。
- Severity: non-blocking

R4
- Risk: `template/` 鏡像漏同步致 SHA-256 mismatch、guard_contract_validator [FAIL]。
- Trigger: 寫單檔忘了立即鏡像；template/.github/skills/bootstrap-prompt-builder/ 子目錄不存在須 mkdir 而忽略；換行 CRLF/LF 差異致 SHA-256 不等。
- Detection: `python artifacts/scripts/guard_contract_validator.py` 列 root↔template SHA-256 mismatch；PowerShell `Get-FileHash -Algorithm SHA256` 比對。
- Mitigation: 寫 root SKILL.md 後立即 PowerShell `Copy-Item -Force`；先 New-Item -ItemType Directory 確保 template/.github/skills/bootstrap-prompt-builder/ 存在；強制 UTF-8 LF（與既有 docs/* 一致）；coding 結束前 SHA-256 驗證 0 mismatches。
- Severity: blocking
