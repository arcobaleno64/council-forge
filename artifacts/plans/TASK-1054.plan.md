## Risks

### R1: PowerShell `$input` quirk 致 mock-side stdin 觀察錯誤，C-2 stdin pipe path 之斷言成立但實際 wrapper 行為失準

- Risk: Stage 3 之 C-2 case 之兩個 prompt（6,999 / 7,001 字）導致 wrapper 觸發 stdin pipe path（per RQ2-F02 之 `:245` `$Prompt | & $Executable ...`），但 fake exe 之 `.cmd` / `.sh` shim 在收到 stdin 時若按 `$input` automatic variable 邏輯讀取，會因 in-session quirk（per RQ3-F01 / F02）讀到空字串或 `__POSITIONAL__` 字面值；test 若以 mock-side stdin marker 為斷言依據，會誤判 wrapper 走 positional path（False negative）。
- Trigger: C-2 case (b) 之 7,001 字 prompt 觸發 wrapper `:232` 之 `$useStdinPipe = $true`，但 fake exe 之 stdin reader 收到 PowerShell pipeline 之 quirk 變形輸入。
- Detection: pytest C-2 (b) 之 invocation log 顯示 `stdin_received_bytes = 0` 但 wrapper log 顯示 `stdin_pipe=True, prompt_size=7001`；兩者矛盾。
- Mitigation: **C-2 case 之 stdin pipe path 斷言完全依據 wrapper-side stderr 之 `[*] Attempt 1/3 (stdin_pipe=True, prompt_size=7001)` log line 字面值**（per RQ2-F04 之 `:236` log line + research C13）；fake exe 不嘗試 inspect stdin（fake exe 僅讀 args、印 stdout、回 exit code）；conftest.py 之 `run_wrapper` helper 不暴露 stdin observation API。Stage 2 之 fixture design 已遵守此約束。
- Severity: blocking

### R2: cross-platform fake-exe shim 在 POSIX runner 失敗，致 CI 不可重現

- Risk: pytest fixture 之 fake exe 採 `os.name` 決定 `.cmd` / `.sh`，但 PowerShell wrapper 在 POSIX 環境下若以 `pwsh` 執行（非 `powershell.exe`），其 `& $Executable` 對 `.sh` 之 invocation 行為可能與 `.cmd` 之 Windows 行為不一致（如 stdin handling、env propagation）；致 same test 在 Windows 通過、POSIX 失敗。
- Trigger: 本 task 之 pytest 在 GitHub Actions Ubuntu runner（屬 TASK-1058 之未來範圍）跑時觸發；或 user 在 WSL / macOS 上跑 pytest。
- Detection: pytest 之 invocation log 顯示 args / exit code 在兩 OS 間不一致；或 wrapper stderr 印 `Cannot execute: <path>` 之 platform-specific 錯。
- Mitigation: conftest.py 採 **保守策略**：(a) `pwsh` 不可用時 `pytest.skip('PowerShell unavailable')`；(b) Windows 採 `powershell.exe -NoProfile`，POSIX 採 `pwsh -NoProfile`；(c) fake exe shim 在 POSIX 採 `#!/usr/bin/env bash` + `chmod 755`，行為儘量對齊 `.cmd`（讀 `$@` / 寫 `$1` 等）；(d) 本 task 之 verify artifact 明確記錄 「primary 驗證為 Windows local；POSIX 屬 best-effort，未 PASS 不阻塞 closure」；(e) PR-030 之 `must_contain_all` 含 `'PowerShell unavailable'` 字串以保 skip path 之顯式存在。
- Severity: non-blocking

### R3: 拆檔後 duplicate class（C16 之 16 對）恢復 collect 致 baseline drift，pytest passed 數與 TASK-1056 之 1166 對不上
