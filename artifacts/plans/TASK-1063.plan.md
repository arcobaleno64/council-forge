**P1 — `.github/workflows/weekly-council-audit.yml`**：

```yaml
name: Weekly Council Audit

on:
  schedule:
    - cron: '0 18 * * 0'  # Sunday 18:00 UTC = Monday 02:00 Asia/Taipei
  workflow_dispatch:

permissions:
  contents: write
  pull-requests: write

jobs:
  council-review:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@<SHA>  # SHA pin via Plan R1-mitigation
        with:
          fetch-depth: 8  # need HEAD~7

      - name: Resolve commit range
        id: range
        run: |
          OLDEST=$(git rev-parse --short HEAD~7)
          NEWEST=$(git rev-parse --short HEAD)
          DATE=$(date -u +%Y-%m-%d)
          echo "oldest=$OLDEST" >> $GITHUB_OUTPUT
          echo "newest=$NEWEST" >> $GITHUB_OUTPUT
          echo "date=$DATE" >> $GITHUB_OUTPUT
          echo "branch=claude/weekly-audit-$DATE" >> $GITHUB_OUTPUT

      - name: Run council review
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
        run: pwsh -File artifacts/scripts/Invoke-CodexReview.ps1 -DiffSource HEAD~7 HEAD -OutputDir "artifacts/reviews/weekly-${{ steps.range.outputs.date }}/"

      - name: Commit + push review
        run: |
          git config user.name "claude-routine[bot]"
          git config user.email "claude-routine@users.noreply.github.com"
          git checkout -b "${{ steps.range.outputs.branch }}"
          git add artifacts/reviews/
          git commit -m "[claude-routine] weekly-audit: ${{ steps.range.outputs.oldest }}..${{ steps.range.outputs.newest }}"
          git push origin "${{ steps.range.outputs.branch }}"

      - name: Open PR
        uses: actions/github-script@<SHA>  # SHA pin via Plan R1-mitigation
        with:
          script: |
            const branch = '${{ steps.range.outputs.branch }}';
            const date = '${{ steps.range.outputs.date }}';
            const range = '${{ steps.range.outputs.oldest }}..${{ steps.range.outputs.newest }}';
            await github.rest.pulls.create({
              owner: context.repo.owner,
              repo: context.repo.repo,
              head: branch,
              base: 'master',
              title: `[claude-routine] Weekly Audit ${date} (${range})`,
              body: [
                '> **Generated by Codex Council Review (GitHub Actions)**',
                '> Source workflow: `.github/workflows/weekly-council-audit.yml`',
                '> Source script: `artifacts/scripts/Invoke-CodexReview.ps1`',
                `> Run window: ${range}`,
                '',
                'Council members reviewed each commit on master in the past 7 commits across three Codex tiers (gpt-5.4-mini / gpt-5.4 / gpt-5.5). See attached review artifact for triage.',
              ].join('\n'),
            });
```

## Risks

R1
- Risk: `actions/github-script@v7.0.1` SHA `60a0d83039c74a4aee543509d22c19323f46f366`（per research §Q3）為 Gemini 寫出但未直接驗證之字面值；若 SHA 不對應 v7.0.1 tag，workflow 跑時 `actions/github-script` 將拉到錯版本或拉不到，導致 Open PR step 失敗或執行任意 code（supply-chain risk）。
- Trigger: 首次 workflow_dispatch 跑時於 `Open PR` step；或 PR review 時 reviewer 對比 SHA 與 GitHub release page 不一致。
- Detection: workflow 跑時 actions/github-script 步驟 fail（`Error: Unable to resolve action ...`）；或 reviewer 跑 `gh api repos/actions/github-script/git/refs/tags/v7.0.1` 對 SHA 不符。
- Mitigation: Coding 階段 implementation 前以 WebFetch（`https://github.com/actions/github-script/releases/tag/v7.0.1`）或 `gh api repos/actions/github-script/git/refs/tags/v7.0.1` 驗證 SHA；若不符則以實證 SHA 替換；同步驗證 `actions/checkout` 之 SHA。Verify 階段以 grep 雙確 yml 字面 SHA 與外部 source 一致；不接受未驗證 SHA 進 master。
- Severity: blocking

R2
- Risk: OPENAI_API_KEY rate limit 或 token quota 不足；首跑或大 commit window 觸發三 tier × 7 commits diff 之 token 用量超過帳戶 TPM/RPM 限制；workflow fail 致 cadence drift。
- Trigger: 首次 workflow_dispatch 跑時；或 master 過去 7 天 commits 含大型 diff（如 大量檔案 rename / refactor）；或帳戶 OpenAI tier 為低階（per research §Q2 platform.openai.com/docs/guides/rate-limits/usage-tiers）。
