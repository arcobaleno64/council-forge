- Trigger: doc 撰寫時為求中文流暢，將 `temp file` 寫成 `暫存檔`，或 `fabrication` 寫成 `捏造`
- Detection: `python artifacts/scripts/prompt_regression_validator.py --root .` 報 PR-031 missing literals
- Mitigation: doc 撰寫先寫 PR-031 之 `must_contain_all` 為 anchor，再回 doc 對應段落確認英文字面值存在；必要時混用「暫存檔（temp file）」雙語並排確保字面 retain
