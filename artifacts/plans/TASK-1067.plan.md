## Risks

R1
- Risk: bounds-check warn / reject message 字面與 PR-032 keyword pin 字面 drift（如 message 寫 "exceeds soft limit 500" 但 PR-032 之 must_contain_all 寫 "500 chars"，導致 prompt_regression_validator FAIL）
- Trigger: wrapper edit 之 string literal 與 PR-032 anchor 之 must_contain_all 寫法不一致
- Detection: `python artifacts/scripts/prompt_regression_validator.py --root .` 報 PR-032 missing literals
- Mitigation: 採 PR-032 keyword pin 為 anchor（"SuppressSizeWarn" / "5000" / "500" / "docs/dispatch_prompt_discipline.md"），wrapper message 寫法 free-form 但必含此 4 字面；commit 前最後一步以 prompt_regression_validator 全綠為通過門檻；若 FAIL 即比對 wrapper 字面與 PR-032 字面差異補齊
- Severity: blocking

R2
- Risk: default-on bounds-check 對既有 weekly-council-audit cron caller（per TASK-1063 之 .github/workflows/weekly-council-audit.yml）破壞性—— review wrapper 之 diff 過 200k 即 reject，cron 無 -SuppressSizeWarn opt-out 即每週中斷
- Trigger: 未來週 commits diff size 超 200k chars（單週 7 commits 大型 refactor 即可能 trigger）
- Detection: weekly-council-audit cron run 之 GitHub Actions log 報 exit 4；PR-021 / weekly artifact 缺失
- Mitigation: (a) review wrapper bounds 採 generous 100k/200k（per F-6 之 64k 實測上限為 reference）；(b) weekly-council-audit.yml 之 pwsh 命令追加 `-SuppressSizeWarn` flag 防 cron 中斷；(c) docs/security_cadence.md §Weekly 段補一行 disclosure；本 task 範圍含 (b) 之 yml 修改（追加 1 行）
- Severity: blocking

R3
- Risk: 三 wrapper ps1 之 bounds-check boilerplate 重複（~12 行 x 3 = 36 行 ps1 string literal 重複），未來修須三處同步；違 DRY 原則
- Trigger: 未來 task 修 threshold 或 message 字面
- Detection: 字面 drift（一 wrapper 改但其他未改）
- Mitigation: 接受 trade-off（ps1 無 import 機制，shared helper 須抽出 .psm1 module；本 task 範圍不含此 refactor）；未來如有需要另立 task 抽 helper module；PR-032 之 must_contain_all 涵蓋三 wrapper 字面，提供 drift detection

- Trigger: 未來 task 新增 wrapper 之 exit code 用 4 為其他語意

- Mitigation: 本 task code artifact 之 §Execution Profile 段記 exit code 分配（0/1/2/3=既有；4=本 task bounds-check reject）；未來 task 須先檢此記錄；同步 docs/dispatch_prompt_discipline.md §5 補 exit code 4 之含意
