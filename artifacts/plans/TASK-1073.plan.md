## Proposed Changes

### CP-1: `overlay_template(template_root, target) -> list[Path]`（新函式，copy-missing-only）

遍 template_root 之檔；對每檔，target 對應路徑不存在則 copy（建中間目錄）、記入 added；存在則**跳過**（never overwrite）。回 added 清單。reuse `iter_files`。

### CP-2: `apply_substitutions(target, mapping, only_files=None)`（擴充既有，加 optional 參數）

加 `only_files: Optional[list[Path]]`；為 None 時行為不變（greenfield 全掃）；給定時**僅**對該清單之檔施替換（retrofit：只替 added 檔，不動既有）。替換/殘留邏輯**重用**既有，不複製。

### CP-3: `scaffold()` 與 `run()` 之 retrofit 分支

`ScaffoldConfig` 加 `retrofit: bool=False`。`scaffold()`：retrofit 時 → `added = overlay_template(...)`；`apply_substitutions(target, mapping, only_files=added)`；strip sentinel；profile（reuse）；guards（reuse，結果 informational）。`run()`：`--retrofit` 時 target 須**存在且非空**（空則提示用 greenfield）；不要求 empty/force；印 added/substituted/guard 報告；overlay 成功 exit 0（guard 不符不致非零——brownfield 既有 artifacts 預期不符，印為 conformance gap）。

### CP-4: `test_scaffold_downstream.py` 補 retrofit 測試

`overlay_template`（missing-only、added 清單）、`apply_substitutions only_files`、retrofit happy path（既有檔 byte 不變、缺檔補上、added 檔替換）、idempotency（再跑 added=0）、run() retrofit 分支（informational guards via monkeypatch）。維持 scaffold ~100%。

## Risks

> 事前驗屍（Premortem）：以下為動手前設想之失敗模式（Risk / Trigger / Detection / Mitigation / Severity 五欄）。

R1
- Risk: overlay 覆蓋既有 brownfield 檔 → 資料損失 / 觸動 Sentinel 凍結 P0 碼
- Trigger: overlay_template 未先檢 target 存在即 copy，或誤用 shutil.copytree(dirs_exist_ok) 覆寫
- Detection: retrofit happy-path 測試以「既有檔內容/sha 不變」斷言；human diff review
- Mitigation: overlay_template **逐檔檢 target 不存在方 copy**；既有檔一律跳過；明確測試覆此不變式
- Severity: blocking

R2
- Risk: 替換污染既有 brownfield 檔（將其 `{{...}}` 或巧合字串替掉）
- Trigger: apply_substitutions 於 retrofit 仍全掃 target
- Detection: 測試斷言既有檔（含一含 `{{PROJECT_NAME}}` 之既有檔）retrofit 後不變
- Mitigation: retrofit 傳 `only_files=added`，替換**僅**施於新補檔
- Severity: blocking

R3
- Risk: brownfield 既有 artifacts 不符 council-forge schema → guard 失敗被誤判為工具 bug 或 retrofit 失敗
- Trigger: retrofit 後跑 downstream guards，既有非 council-forge artifact 報 FAIL
- Detection: throwaway brownfield（含一非 council-forge artifact）retrofit 後 guard 報告
- Mitigation: retrofit guards 為 **informational**（印 conformance gap，不令 generator 非零退出）；文件明示「retrofit guard 輸出＝待映射之 gap 報告，非 pass gate」
- Severity: non-blocking

R4
- Risk: idempotency 破——再跑 --retrofit 重補或改既有
- Trigger: overlay 未正確跳過既存
- Detection: idempotency 測試（第二次 added=0、檔不變）
- Mitigation: copy-missing-only 天然 idempotent；測試守之
- Severity: blocking

R5
- Risk: coverage 退步（retrofit 新分支未覆）或 CLI glue 計入
- Trigger: 新 overlay_template/retrofit 分支無測
- Detection: pytest --cov term-missing
- Mitigation: CP-4 補全分支測；不可測之 OS 例外行方許 `# pragma: no cover` + 理由
- Severity: blocking

R6
- Risk: 疊床架屋——retrofit 另寫平行 copy/substitute 邏輯而非重用
- Trigger: 圖快而複製 greenfield 邏輯
- Detection: code review；DRY 檢（overlay 僅新增 copy-missing；substitute 重用加參數）
- Mitigation: 嚴守 CP-1/CP-2 之「擴充既有、加參數」設計；不複製
- Severity: non-blocking
