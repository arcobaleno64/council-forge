## Proposed Changes

### CP-1: harden council-forge 自身 security-scan.yml（root + template）
- pip-audit 安裝由 `pip install pip-audit`（未釘）改 **`pip install pip-audit==<pinned>`**（實作時取 verified-current 穩定版，附「定期 bump」註）。
- **棄所有 exit-masking**（codex v3 [high]）：pip-audit 為**單一 enforcing step** `python -m pip_audit -r requirements.txt --format=json --output=pip-audit-report.json`（命中 vuln 即非零→job 敗，**無 `|| true`**；同時產 JSON 報告），後可接 `cat pip-audit-report.json` 純展示（不影響 exit）。**無 advisory `|| true` 例外**——故 CP-8 lint 可無例外禁 masking。
- secret/static job 沿用 `repo_security_scan.py secrets/static`（已 fail-closed），不改。
- **避免疊床架屋**：不引 gitleaks/trufflehog（repo_security_scan.py 語言無關已足）。

### CP-5: sca_gate.py（有測之 fail-closed SCA gate，source-only + template + EXACT_SYNC）
新增 `artifacts/scripts/sca_gate.py`（+ `template/artifacts/scripts/sca_gate.py`，加入 EXACT_SYNC_FILES 使二者 byte 同步、propagate 至下游），統一 fail-closed 之 SCA 判定（尤 .NET 之 exit-0-with-vulns 陷阱）：
- `dotnet`：讀 `dotnet list package --vulnerable --include-transitive --format json` 之 JSON——任一 package 之 `vulnerabilities` 非空 → exit 1；**JSON malformed / 無 projects（restore 失敗）/ 空輸出 → exit 1（fail-closed，不 false-pass）**；無 vuln → exit 0。
- **schema 結構驗證（gemini v4 [medium]，杜 SDK 格式漂移之 silent 誤判）**：須具預期結構（`version` 欄 + `projects[].frameworks[].topLevelPackages|transitivePackages[].vulnerabilities` 形）；**結構非預期（缺 version/projects 非 list/framework 形不符）亦 exit 1（fail-closed）**，不假設無 vuln。模板 CP-6 註明 pin setup-dotnet 版。
- 統一 CLI：`sca_gate.py dotnet --json <file|->`；read-only、無 subprocess（純解析，同 P8-A validator 之邊界）。
- 100% cov：fixture vuln（→1）、clean（→0）、degraded（malformed/empty/no-projects→1）、**schema 非預期（→1）**。

  - **Rust SCA**：`cargo install cargo-audit --version <pinned> --locked` → `cargo audit`（非零即敗）。
  - **.NET SCA**：`dotnet list package --vulnerable --include-transitive --format json > vuln.json` → `python artifacts/scripts/sca_gate.py dotnet --json vuln.json`（**有測之 gate，非 raw grep**）。
- `docs/templates/security/README.md`：採用指引 + 啟用矩陣（CP-7）+ 「pin 須定期 bump」註。

### CP-8: action-pin manifest + comprehensive 模板 lint 測（杜供應鏈 + 所有 exit-masking）
- `docs/templates/security/action-pins.json`（**manifest**）：approved actions 之 `{ "owner/repo": {"version": "<tag>", "sha": "<40-hex>"} }`（checkout/setup-python/setup-node/setup-dotnet；SHA 於實作時自 release tag 解析）。
- `test_downstream_security_template.py`（PyYAML **parse jobs/steps**，非僅字串）：
  - **供應鏈（涵三類 workflow）**：lint 輸入 = `.github/workflows/security-scan.yml` + `template/.github/workflows/security-scan.yml` + `docs/templates/security/downstream-security-scan.yml`；**每** `uses: X@Y` → X 須在 manifest 且 Y == manifest[X].sha（**identity + 精確 SHA**）；負測：unknown action、same-SHA-wrong-owner、known-action SHA-drift 皆 fail。

  - **pin**：pnpm/cargo-audit/node 具體版本 pin 在；pip-audit（CP-1）釘版。
  - **gate 路徑**：dotnet job 呼 `sca_gate.py`（非 raw grep）；secret job 呼 `repo_security_scan.py`。
