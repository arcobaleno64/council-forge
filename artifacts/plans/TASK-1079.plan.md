## Proposed Changes

### CP-1: version-值 fail-closed 校（evaluate_dotnet）
- 加常數 `SUPPORTED_DOTNET_REPORT_VERSIONS = frozenset({1})`（docstring 註：dotnet `--format json` report format version；未知版本 fail-closed 以防同結構改欄之 silent drift；經 schema 人工驗後方加新版本）。
- `evaluate_dotnet`：現「`if "version" not in payload: return _fail(...)`」之後，加**精確 int 型檢**（codex v1 [high]，杜 Python `True == 1` 致 `"version": true` 誤過）：
  ```
  report_version = payload["version"]
  if type(report_version) is not int or report_version not in SUPPORTED_DOTNET_REPORT_VERSIONS:
      return _fail(f"unsupported dotnet report version {report_version!r} — verify schema then update sca_gate")
  ```
  （`type() is int` 排除 `bool` 子類；string/bool/未知 int 皆 fail-closed。）
- 其餘 fail-closed 邏輯（projects/frameworks/buckets/package/vulnerabilities 型檢、empty-projects）不動。

### CP-2: EXACT_SYNC 鏡像
- cp root sca_gate.py → template；sha256 驗 SYNC。

### CP-3: 補測（100% cov 不退）
- `test_sca_gate.py` 加 `test_eval_unsupported_version`：`{"version": 2, "projects": [...valid...]}` → exit 1 且 msg 含「unsupported」「2」。
- **bool/string regression（codex v1 [high]）**：`{"version": true, "projects": [...vuln-less...]}` → exit 1（非誤判 version 1 之 clean）；`{"version": "1", ...}` → exit 1。
- 既有 24 測（含 clean version 1 → 0、vuln version 1 → 1、missing-version → 1）不破。

## Risks

> 事前驗屍（Premortem）：Risk / Trigger / Detection / Mitigation / Severity。

R1
- Risk: 弱化既有——version 校誤擋合法 version-1 之 clean/vuln（致 false-fail，破壞 TASK-1078 行為）
- Trigger: 校邏輯置於型檢之後、或誤判 int 1
- Detection: AC-3（六真實案不變）；既有 24 測；新增 clean/vuln version-1 路徑仍綠
- Mitigation: 校置於「version 存在」檢之後、結構型檢之前；`1 in {1}` 為 int 相等；既有 fixture 皆 version 1，測證不退
- Severity: blocking

R2
- Risk: 過嚴 false-fail——dotnet 若以 string "1" 或其他相容形出 version，被 fail-closed

- Mitigation: 以實證之 int 1 為準；fail-closed 偏向乃安全 gate 之刻意取捨（未知形寧失敗待人工驗）；訊息明示需更新 gate；README bump cadence 涵運維
- Severity: non-blocking

R3

- Trigger: 為「相容未來」做版本適配
- Detection: task §Out of Scope
- Mitigation: 僅加 frozenset 成員檢；不做適配；新版本俟真出且人工驗 schema 後再加入集
- Severity: non-blocking

- Trigger: 漏 cp template；新分支未覆
- Detection: guard_contract（EXACT_SYNC）；cov term-missing
- Mitigation: cp + sha 驗；補 test_eval_unsupported_version；sca_gate 100% 不退
- Severity: non-blocking
