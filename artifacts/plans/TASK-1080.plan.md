## Proposed Changes

### CP-1: sast_gate.py（source+template+EXACT_SYNC，fail-closed SARIF gate）
- 讀 SARIF（`--sarif <file|->`）。**schema 校（承 TASK-1079）**：SARIF `version` 欄為**字串**"2.1.0"；`SUPPORTED_SARIF_VERSIONS = frozenset({"2.1.0"})`；`type(version) is not str or version not in SUPPORTED → fail-closed`（杜 SDK/tool 格式漂移之 silent）。
- 解析 `runs`（list）`[].results`（list）`[].ruleId` + location + **`level`**。**`level` 嚴校（gemini v3 [medium]，杜未知 level 之 false-negative）**：`SUPPORTED_SARIF_LEVELS = {"error","warning","note","none"}`；level 缺省為 SARIF 規範之 `"warning"`；**未知 level 值（非字串/不在集）→ fail-closed exit 1**（承 version fail-closed 偏向，不 silent 略過）。結構非預期 / malformed / empty-非-SARIF → **fail-closed exit 1**（gate 不信任壞輸入，advisory 亦然——「不能對 garbage 建議」）。
- **verdict 語意（advisory-first）**：valid SARIF 時——`advisory`（**預設**）：印 findings 計數/最高 level 摘要，**exit 0**（不因 findings 失敗）；`--enforce --min-level {error,warning}`：findings 達 min-level→**exit 1**，否則 0。
- **durable 暴露（gemini v3 [high] / codex v4 [high]）**：`--summary-file <path>` 將 **per-finding markdown 摘要 append 至指定檔**（CI 用 `$GITHUB_STEP_SUMMARY`），使 advisory findings 於 job 後仍可審——杜「reporting-not-control」。免新 GitHub Action（避未驗 SHA）。
- exit：`0`=valid+（advisory 或 enforce 下未達標）；`1`=findings 達標（enforce）**或** fail-closed（malformed/unknown-version/結構壞）；`2`=usage/IO。read-only、無 subprocess（同 sca_gate 邊界）。
- 加入 EXACT_SYNC_FILES（root+template guard_contract）。100% cov。

### CP-2: repo_security_scan.py `sast` 子命令（advisory Python SAST，emit SARIF）
- 加 `sast` subparser（與 secrets/static 並列）+ `PYTHON_SAST_RULES`（curated 高信心低-FP：`yaml.load` 無 SafeLoader、`pickle`/`marshal` load、`tempfile.mktemp`、`hashlib.md5|sha1` 充安全雜湊、`assert` 充驗證、bind `0.0.0.0`、`ssl ... CERT_NONE`）。
- **emit SARIF 2.1.0**（`--format sarif`；既有 json/markdown 不動）：findings→`runs[0].results[]`（ruleId/level/message/location）。
- **advisory**：`sast` 子命令 exit 0（報而不敗；`--enforce` 旗標可後階轉 exit 1）。**既有 secrets/static enforcing 行為完全不變**（不改其 STRUCTURED_SECRET_PATTERNS/STATIC_RULES/main 之 `1 if findings`）。
- template 鏡像（repo_security_scan.py 現有 template 副本；本 task 將其加入 EXACT_SYNC 以防 drift，或手動 cp+sha 驗——擇 EXACT_SYNC 為紀律）。
