### CP-1: sbom_gate.py（source+template+EXACT_SYNC，fail-closed CycloneDX gate）
- 讀 CycloneDX JSON（`--sbom <file|->`）。輕量 stdlib json+檢（**非**全 schema validator——避免疊床架屋；同 sca/sast gate read-only 無 subprocess 邊界）。
- **schema 校（fail-closed，承 TASK-1079/1080）**：
  - top-level 須 dict，否則 fail-closed。
  - `bomFormat` 須 **精確** == `"CycloneDX"`（str），否則 fail-closed。**精確之據（gemini v1 [high] 駁）**：CycloneDX JSON schema 定 `bomFormat` 為 `const: "CycloneDX"`；非精確值即 spec 違例，fail-closed gate 應拒（不 lower-case 寬縱，否則納 spec 違例之 SBOM、弱化 fail-closed）；四 canonical 生成器皆出 canonical casing。code 註引 schema const。
  - `specVersion`：`SUPPORTED_CYCLONEDX_VERSIONS = frozenset({"1.2","1.3","1.4","1.5","1.6","1.7"})`（**納 1.7**，杜下游 .NET 預設 1.7 之強制降版 data-loss；gate 所校欄跨 1.2-1.7 皆穩）；`type(specVersion) is not str or specVersion not in SUPPORTED → fail-closed`（杜工具/格式漂移之 silent）。
  - `version`（BOM revision）若存在：`type() is int and not bool and >=1`，否則 fail-closed。
  - `components`：**缺 或 `[]` → 視為 count 0**（不另放行）；若存在須 list（非 list→fail-closed）；每 entry dict 具非空 str `name` + str `type`。**per-specVersion type allowlist（codex v4 [critical]，非 union——杜 schema-drift false-pass）**：`TYPES_BY_VERSION` 依該 BOM 宣告之 `specVersion` 取對應 type 集校之——`BASE8`（1.2/1.3/1.4：application/framework/library/container/operating-system/device/firmware/file）；1.5 = BASE8 ∪ {platform, device-driver, machine-learning-model, data}（12）；1.6/1.7 = 1.5 ∪ {cryptographic-asset}（13）。**newer-only type 於舊版 specVersion → fail-closed**（如 1.4 帶 cryptographic-asset 拒）。type 不在「該版」集→fail-closed。
  - **`--min-components N`（預設 1）**：`count(components) < N → fail-closed`（codex v3 [critical]：**缺/空 components 於預設 min=1 下即 fail-closed**＝生成失敗/空 SBOM 之防，類 sca_gate empty-projects；**唯 `--min-components 0` 方放行**缺/空——明予零依賴專案之逃生口，非預設）。
  - **completeness：identity 檢（codex v5/v6 [critical] + gemini [critical]，count-only 不足）**：`--min-components N`（presence 下限，杜空/too-few）**＋** **`--require-components <names>`（identity）**——**CI job 由 manifest 取直接依賴「名」**傳入，sbom_gate 斷言 SBOM `components[].name` **含各必備名**，缺→fail-closed。閉「count-only 被足量 unrelated 騙過 / 錯環境 / 缺直接依賴」。**gate 仍 generator-agnostic**：只檢「被告知之名」，生態知識留 job。
  - **CLI 契約（codex v6 [high]，杜退回 count-only）**：`--require-components` 收 **comma-separated**；gate split→strip→**棄空 token**；**flag 既給卻得空名集 → fail-closed exit 2**（非空 manifest 經 parser 失敗致零名，不得 silent 退 count-only）；多名則**每名皆須 present**（缺一即 fail-closed）；未給該 flag 則略 identity（僅 min-components）。
  - **ecosystem-aware normalization（codex v6 [critical]）**：`--name-normalization {exact, pep503}`（**預設 `exact`**）——`pep503`（lower + run-of-`-_.`→單 `-`，PyPI 用）；`exact`（保標點/scope，**npm/Cargo 用**，杜 `foo_bar` 矇 `foo-bar`）。Python job 傳 `pep503`、npm/Cargo 傳/留 `exact`。負測：npm `foo-bar` vs SBOM `foo_bar`/`foo.bar` 於 exact **fail-closed**。
  - **completeness 之誠實界 + ACCEPTED RISK（gemini v7 收斂）**：gate **fail-closed** 驗 well-formed + presence + **直接依賴 identity**（此為 gate-checkable 之 sound 上限）。**窮盡 transitive completeness vs 真實 graph 無任何 gate 能獨立斷**（除非自為生成器、或另信一其完整性同不可由 gate 證之 enumerator＝無限回歸；gemini v7 經詰問未能給出 gate-side 檢法，實證此界）——故**明標為本階 explicitly ACCEPTED RISK**（非「sound for ALL completeness」之過稱）：由 resolved-env 配方（構造捕 transitive）+ identity（直接依賴 fail-closed）+ 恆印 advisory 共治，殘留以 §Transitive-Completeness Follow-up 之**非阻斷週期審計**（SBOM vs 獨立 graph）為 feedback loop。**不**將恆存固有侷限之 advisory 設為 per-run build-break（永紅/恆 override＝theater，gemini v7 已撤此索求）。
- **completeness 邊界（誠實，貫 codex[high]/gemini[crit]/[high]）**：sbom_gate 校 **well-formedness + presence（min-components）**，**非** completeness-vs-actual-dependency-graph——一不全卻 well-formed 之 SBOM 仍會 pass。completeness 繫於各生態**生成配方正確**（Python resolved env、Rust all-members、Node pnpm→cdxgen）。此邊界明載 code docstring + mapping/README。
- **恆印 completeness advisory（gemini v2 [high]，不可忽略）**：sbom_gate **每次執行**（含 pass）皆於 stdout **與** `--summary-file` 印一高顯著 advisory 行——明「本 gate 驗 well-formed+presence，**非** completeness vs 真實 dep graph；一不全卻 well-formed 之 SBOM 仍會過關，務必確認各生態生成配方正確（resolved-env / all-members / pnpm→cdxgen），否則恐漏元件之漏洞」。杜「pass＝fit-for-purpose」之誤讀。**不** arbitrary fail（gate 無從知真實 graph，妄敗為錯）；以不可忽略之警示 + 強制正確配方（CP-2/CP-4 + lint 測）共治之。
- **verdict**：valid + components>=min → exit 0 + 摘要（component 計數、specVersion、type 分佈）；malformed/unknown-version/bomFormat 錯/結構壞/<min → **fail-closed exit 1**；usage/IO → exit 2。

- 加入 EXACT_SYNC_FILES（root+template guard_contract）。100% cov。
