## Proposed Changes

### CP-1: security_txt_gate.py（source+template+EXACT_SYNC，fail-closed RFC 9116 gate）
- 讀 `security.txt`（`--file <path|->`）。輕量 stdlib（datetime RFC3339；不引第三方 lib）。read-only 無 subprocess（同 gate 家族邊界）。
- **行法**：忽略空行與 `#` 註解行；每非空非註行須 `Name: value`（name+value 皆具，否則 fail-closed）；field 名**大小寫不敏**。UTF-8（不可解→fail-closed）。
- **field allowlist（RFC 9116 IANA 註冊表，snapshot 2026-06-08）**：`SUPPORTED_FIELDS = {acknowledgments, bug-bounty, canonical, contact, csaf, encryption, expires, hiring, policy, preferred-languages}`（小寫；**含 codex[h2] 所揭之 `bug-bounty`**）；未知 field→**fail-closed**（schema-drift 紀律，承 sbom_gate；gate 內記 registry snapshot 日，文記新 IANA field 需 gate 更新，同 tool-pin bump cadence）。
- **URI-valued field 結構驗（codex[h1]/[v2 h1] + gemini[crit]，IANA registry 核實）**：`URI_FIELDS = {acknowledgments, canonical, contact, csaf, encryption, hiring, policy}`（**7 個 URI-valued field；不含 bug-bounty/expires/preferred-languages**）——每值以 `urllib.parse.urlsplit` 結構驗：scheme 具 + scheme-specific remainder 非空；**`http` scheme → fail-closed**（RFC 9116 §2.7.2：web URI MUST https）；`https` → 須 netloc（host）；`mailto` → 須含 `@`；`tel` → 須非空；malformed/缺 scheme/空值 → fail-closed。**Contact** 另須 ≥1 次（缺→fail-closed）。
- **Bug-Bounty（codex v2 [h1]，別治非 URI）**：值須 `True`/`False`（**case-insensitive**，否則 fail-closed）；**不入 URI_FIELDS**；at-most-once。
- **Expires**：**恰一次**（缺/重→fail-closed）；值須解析為 **RFC 3339 date-time**（含 `Z`/小寫 `z`/offset 正規化；無 tz→fail-closed 要求明示；不解→fail-closed）；**須 > now**（過期→fail-closed）；`now` 為注入參（預設 `datetime.now(timezone.utc)`，測可注）；`--max-validity-days`（預設 365）：`Expires - now > max → fail-closed`（RFC SHOULD < 1yr）。
- **cardinality（IANA "multiple: no"）**：`NO_REPEAT = {expires, preferred-languages, bug-bounty}` 不得重（重→fail-closed）；`Contact`/`Canonical`/`Encryption`/`Acknowledgments`/`CSAF`/`Hiring`/`Policy` 可重。
- **恆印 advisory（誠實界 + human-review 補償，gemini[crit]）**：gate 驗檔之 **well-formed + URI 結構 + https-for-web + 必備 field + 未過期**；**不能**驗 Contact 真達責任人/真有人監看、Policy/Canonical URL 可達（網路逾 no-subprocess 邊界）、URI 非 phishing/惡意、OpenPGP 簽章真偽——**此語義可信屬 human-review**（security.txt 變更之 PR review + disclosure policy owner），非 gate；且 Expires 僅檢**當下**有效，不保證續期→**須 scheduled CI**（cron）防無聲過期。此殘留為 explicitly accepted-risk。
- exit：`0`=valid+未過期；`1`=fail-closed（malformed/未知 field/缺 Contact/Expires 缺·重·不解·過期·過長）；`2`=usage/IO。
- 加入 EXACT_SYNC_FILES（root+template guard_contract）。100% cov。
