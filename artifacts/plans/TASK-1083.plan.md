### CP-1: release_gate.py（source+template+EXACT_SYNC，fail-closed family gate，唯 checksums format）
- shebang + docstring（首行 `release_gate.py — fail-closed release-integrity (checksums manifest) structural gate.`；列每 fail-closed 條件 + HONESTY BOUNDARY 段（驗結構非密碼學）+ `Source-only + mirrored into template/ (and EXACT_SYNC).` + `Read-only, pure parsing — no subprocess and no network, matching sca/sast/sbom/security_txt_gate.`）。`from __future__ import annotations` 首。stdlib only：argparse/json/sys/re + typing（**無第三方、無 subprocess、無網、無寫**除 `--summary-file` append）。
- exit：`EXIT_OK=0`；`EXIT_FAIL=1`（fail-closed：malformed/schema-drift/missing-required/bad-digest/placeholder/coverage-gap）；`EXIT_USAGE=2`（usage/IO；`--require-paths` 給而空→拒靜默降級→EXIT_USAGE）。`stream = sys.stderr if code != EXIT_OK else sys.stdout`。
- **常數**：`ALGO_ALLOWLIST = {"sha256":64, "sha512":128}`（algo→hex 長）；`SUPPORTED_SCHEMA_VERSIONS = frozenset({"council-forge/release-manifest@1"})`（schema 欄 const allowlist，未知→fail-closed，承 sbom_gate schema-drift；註「新 schema 須先驗+更新 parser 方加」）；`_HEX_RE`、placeholder/sentinel 集。
- **fail-closed helper**：`is_str(x)=type(x) is str`（**非 isinstance**，避 bool/`"1"` 偽裝，承 sca_gate）；`validate_digest(algo, value)`（is_str + 長度==ALGO_ALLOWLIST[algo] + `^[0-9a-f]+$` + reject_placeholder）；`reject_placeholder(value)`（全零/單一 nibble 重複/空/`TODO`·`CHANGEME`·`REPLACE`·`XXXX`（不分大小寫）→fail）；每巢狀容器 isinstance(list/dict) 形檢，意外→`EXIT_FAIL` 帶 `unexpected manifest: ...`（schema 意外絕不讀作「integrity verified」）。
- **`evaluate_checksums(payload, *, require_paths, min_entries)->(code,msg)`**（純函式）：top-level dict；`schema`∈SUPPORTED_SCHEMA_VERSIONS（未知→fail）；`algorithm`∈ALGO_ALLOWLIST；`entries` 非空 list（>=min_entries）、每 entry `{path:str 非空, <algorithm>:hex}`（validate_digest）；**path 唯一**（重→fail）；`root`（validate_digest）；`--require-paths`（給定→entries.path 須恰涵之 set，identity 非僅 count，缺/餘→fail）。
- **`COMPLETENESS_ADVISORY`**（module-level，恆印每次含 pass，可入 `--summary-file`）：`[ADVISORY] release_gate validates checksums-manifest STRUCTURE (schema, algorithm, digest shape, no placeholders, path coverage) — it does NOT cryptographically verify signatures, certificate trust, key/signer identity, transparency-log inclusion, or that digests match real artifact bytes. Real cryptographic verification (cosign / gh attestation verify / dotnet nuget verify / minisign -V) and key-trust remain a separate, native-tool, human-reviewed step and an explicitly accepted residual risk. in-toto/Sigstore/Tauri structural+crypto validation is delegated to those native tools (map-don't-recreate), not re-implemented here.`
- `read_source(path)`（path 或 `-` stdin）；`load_json(text)->(payload,error)`（空/whitespace→`empty output` error→fail-closed）；`parse_args`（`--format` choices=["checksums"] required、`--file` required、`--require-paths`（逗號分隔）/`--min-entries`（預設 1）/`--summary-file`）；`run()` orchestrate（OSError→EXIT_USAGE；JSON/schema error→EXIT_FAIL `failing closed`；append_summary OSError→EXIT_USAGE）。
- tail boilerplate byte-同家族。加入 EXACT_SYNC_FILES（root+template guard_contract）。100% cov（依 .coveragerc 既有 exclude_lines）。**in-toto/Sigstore/Tauri 不入**（主公裁，native tool 主驗）。

### CP-2: snapshot_manifest.py（source-only generate/verify，determinism + content-address）+ 刊布 .well-known/release-manifest.json
- **`snapshot_manifest.py`**（source-only，**不**入 template/、**不**入 EXACT_SYNC——同 propagate_downstream.py/drift_dashboard.py；docstring 明載 source-only 理據 + inclusion 規則）：stdlib（hashlib/json/pathlib/argparse）。
  - `compute_manifest(template_root)->dict`：走訪 `template_root` 下**全 regular file**，**exclude**（G2）目錄/檔名匹配 `EXCLUDE`={`.git`,`__pycache__`,`.mypy_cache`,`.pytest_cache`} 或 suffix∈{`.pyc`,`.pyo`,`.swp`} 或名∈{`.DS_Store`,`Thumbs.db`} 或 `~` 結尾；path 以 **`PurePosixPath`/`as_posix`** 正規化（`/` 分隔，跨 OS，R9）；`sorted(entries, key=path)`；逐檔 sha256；`root`=sha256 over 排序之 `f"{path}\0{digest}\n"` 串接。輸出 `{"schema":"council-forge/release-manifest@1","algorithm":"sha256","entries":[{"path":..,"sha256":..},...],"root":..}`。**`root` 即 content-address/識別**（C2）；**無 wall-clock 欄**（byte-可復現之必要）。
  - `generate`（`--template-root`/`--output`）→ 寫 manifest（穩定序）。
  - `verify`（`--template-root`/`--manifest`）→ 重算 + 與給定 manifest 深比（entries+root），不符→`EXIT_FAIL=1` 列差異（新增/缺漏/digest 變）；符→0。tamper-evident。
  - exit 0/1（usage→1，同 propagate 紀律）。
- **`.well-known/release-manifest.json`**（council-forge 自身，coding 末以 `generate` 產、覆當前 `template/` 樹）：PS.2.1「make integrity verification info available to acquirers」之刊布錨（`.well-known/` web-publishable，承 security.txt 同址）。**不**入 template/（下游自產）。
- 端到端：`release_gate.py --format checksums --file .well-known/release-manifest.json` → exit 0（CP-6；acquirer 自 `template/` 樹獨立 `verify` 復現，賴 `root` content-address + git per-commit 不可變）。

### CP-3: propagate fail-closed 驗（零 bypass + 記 root）+ CI release-integrity job
- **`propagate_downstream.py`**（source-only，**transactional preflight→apply，CV2**）：`--apply` 採兩相，**任何檔變更前先 preflight 所有 target**：
  - **(I) PREFLIGHT（對所有 target downstream，於任何 copy 前）**：① 重算 source `template_root` 樹之 manifest、與刊布 `.well-known/release-manifest.json` 深比（import 復用 snapshot_manifest.compute_manifest，避重造）；不符或無 manifest→**拒釋**（`EXIT_ERROR`，「run snapshot_manifest.py generate」）；**逕刪 `--skip-manifest-check`**（G4，零 bypass）。② 對每下游檢 marker ownership：`.council-forge/release-snapshot.json` absent→可 create；existing 驗為 council-forge release-snapshot schema（`schema` 欄符）→可 update；**malformed/非-council-forge-owned→FAIL**。**任一 target preflight 敗→於任何檔變更前 abort（exit≠0），不留半套用**（codex v4[h2]）。
  - **(II) APPLY（preflight 全通方行）**：逐下游 **per-file atomic** copy template 檔（每檔 `shutil.copy2`→**temp 同目錄**→`os.replace`，CW2：**永無半寫/損檔**）+ 寫 durable **namespaced** `.council-forge/release-snapshot.json`（committed 於下游）＝`{schema, released_snapshot_root, algorithm, propagated:[{path,sha256}]}`——acquirer **durable 持其所收 snapshot 之 verifier**（PS.2.1「available to acquirers」真義，非 ephemeral stdout）；`root` 繫於刊布 manifest（propagated digest 為其 entries 子集）。**atomic write（CV3/CW2）**：content 檔與 marker 皆 temp 建於 **同目錄**（保同卷→`os.replace` win32+POSIX atomic）、失敗清 temp 而舊檔不動；支援域＝本地 git 工作樹（local FS，文記）。markdown/json 亦載 `released_snapshot_root`（可溯）。anti-theater binding（C2/CH1/CM1）。
  - **誠實界（CW1/CW2，codex v5/v6 + gemini v6[high]）——不偽稱跨 repo 原子性，然 per-file atomic + verified recovery**：① preflight-detectable 敗（manifest 不符/無、marker malformed/非-owned）**於任何寫入前攔截→無半套用**；② **每檔 copy per-file atomic（temp 同目錄→`os.replace`）→永無損/半寫檔**（除 gemini v6 corruption 慮）；③ **cross-file 不完整**（apply-phase 中斷致部分檔已更新）**屬良性且可復原（verified-recovery design，免顯式 rollback，gemini path-b）**——各檔皆完好、**下游為 git repo→partial 全可見於 `git diff`/`status`、可 `git checkout` 復原** + **idempotent 重跑補全** + 刊布 manifest verify + drift_dashboard 偵測。**全量 cross-target staged-transaction rollback 列 defined follow-up**（codex v6 已許非 blocking；跨 repo 真原子性屬過度設計，違 simplicity-first/[[avoid-over-layering]]）。
  - **propagation state-change scope（CW3，gemini v7[high]）——明文界定**：propagate `--apply` 之全部下游變更＝① content 檔（**per-file atomic**）；② parent-dir `mkdir(parents=True, exist_ok=True)`（**idempotent**，重跑無害）；③ copy2-preserved 檔 metadata（mtime/mode，重跑重套）；④ marker（atomic）。**無檔/目錄刪除**（propagate 僅 refresh/add，不刪——故無「刪到一半」之非-content 不一致）。故非-atomic 之唯一面（dir mkdir）為 idempotent，verified-recovery（git + 重跑）涵蓋全 state；無 manifest/os.replace 未覆之隱性 state 變更。
- **security-scan.yml（root+template）加 `release-integrity` job**：checkout（v6.0.2 pinned-SHA、persist-credentials:false）+ setup-python（v6.2.0、3.11）→
  - step A「Verify published release manifest matches the template snapshot (HEAD consistency)」：`python artifacts/scripts/snapshot_manifest.py verify --template-root template --manifest .well-known/release-manifest.json`（regenerate-diff，僅證 HEAD manifest 追 HEAD 樹）。

## Risks

> 事前驗屍（Premortem）：Risk / Trigger / Detection / Mitigation / Severity。

R1
- Risk: 誠實高估——PS.2 宣 covered；或 validator 宣 exit 0/「零 gap」被讀作 SSDLC 認證（codex[crit]+gemini[h1]）
- Trigger: 圖升 covered；誤稱 exit 0 milestone
- Detection: 雙審；親核 validator 源碼（has_open_items=partial∨gap→exit 3）；測斷言 PS.2==partial、validator exit 3
- Mitigation: PS.2 **升 partial 非 covered**（Example-1 上限）；**validator 仍 exit 3**（gap 0 但 14 partial→open items；exit 0 須全 covered，不偽造）；**全棄 exit-0 框架**；mapping/roadmap + header 明載「非認證」；真簽章=path-to-covered 緩
- Severity: blocking

R2
- Risk: theater／弱 PS.2.1——manifest 不可復現、可變未 snapshot-bound、靜默漂移、歷史 acquirer 失 verifier（codex v1/v2[high]+gemini[h2]）
- Trigger: manifest 含 wall-clock/cruft 致不可 byte-復現；覆寫同址致歷史不可驗；所釋 root 僅 ephemeral stdout
- Detection: CP-2 決定性測（兩算 byte-同）+ exclude 測；CP-3 CI step A regenerate-diff；CP-6 content-address 回歸 + durable 歷史可驗回歸 + tamper 測
- Mitigation: manifest **無 wall-clock + 明確 exclude + POSIX 正規化**（byte-可復現）；**`root` content-address**（snapshot-A 永可驗，賴 git per-commit 不可變）；**propagate `--apply` 寫 durable downstream-visible `.council-forge/release-snapshot.json`（CH1，fail-closed ownership CM1）**（acquirer 持其所收 verifier，非 stdout）；claim 降級（CI 僅證 HEAD 一致）；CI regenerate-diff + schedule 防腐；全量 immutable archive=PS.3-鄰緩（partial 不必）
- Severity: blocking

R3
- Risk: template 散播即敗下游（承 P8-D codex[h3]）+ 空檔誤觸 guarded step（gemini[h3]）+ **guard masking 必要 evidence**（codex v2[h2]：AND-manifest 致 council-forge 自身 manifest 缺則 skip 非 fail）

- Severity: blocking

R4

- Trigger: isinstance 寬縱（bool 為 int 子類）；schema allowlist 漏；缺 const 檢

- Mitigation: `type(x) is str`（非 isinstance，承 sca_gate）；SUPPORTED_SCHEMA_VERSIONS frozenset（未知→fail-closed）；每巢狀容器形檢；schema 意外→EXIT_FAIL（絕不讀作 verified）；placeholder/sentinel 嚴拒
