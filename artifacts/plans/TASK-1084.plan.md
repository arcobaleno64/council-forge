## Proposed Changes

### CP-1: CI release-integrity job native-verify step（root+template；fingerprint-pin；base gate 恆跑）
- security-scan.yml `release-integrity` job：**既有 snapshot_manifest verify + release_gate step 一字不動**（維 sentinel-only `if: hashFiles('.council-forge-source-repo') != ''`，**恆跑**——杜 C-H1 遮蔽 base manifest gate）。
- 於其**前**插入 native-verify step「Verify release-manifest signature (native gpg; REAL cryptographic check)」：
  ```
  if: ${{ hashFiles('.council-forge-source-repo') != '' && hashFiles('.well-known/release-manifest.json.asc') != '' && hashFiles('.well-known/release-signing.pub') != '' }}
  env:
    EXPECTED_SIGNING_FINGERPRINT: ""   # operator pins the out-of-band-published fingerprint here (empty -> step skips until provisioned)
  shell: bash
  run: |
    set -eo pipefail                          # explicit: do not rely on the runner default (codex v3)
    test -n "$EXPECTED_SIGNING_FINGERPRINT"   # refuse to verify against an unpinned key (no blind trust)
    export GNUPGHOME="$(mktemp -d)"           # isolated keyring (codex v2 H2)
    gpg --batch --import .well-known/release-signing.pub
    # Bind verification to the PINNED SIGNER, not the pubkey file's first key. gpg --verify exits
    # 0 on ANY good signature from ANY imported key, so an attacker key appended to the bundle
    # (pinned key kept first) would pass a file-first-fpr check while a signature made by the
    # attacker key still verifies. VALIDSIG carries the ACTUAL signing/primary key fingerprint;
    # require it to equal the pinned anchor. (codex v2 [H2])
    #
    # CAPTURE-then-grep (NOT a pipe into grep): the gpg return code is checked DIRECTLY at the
    # assignment under set -e (a non-zero gpg -> failed command substitution -> step fails), so a
    # degraded/bad signature cannot be masked by a status stream that merely contains a matching
    # VALIDSIG line. The final grep then binds the signer fingerprint. (codex v3)
    STATUS="$(gpg --batch --status-fd 1 --verify .well-known/release-manifest.json.asc .well-known/release-manifest.json)"
    printf '%s\n' "$STATUS" | grep -q "^\[GNUPG:\] VALIDSIG .*${EXPECTED_SIGNING_FINGERPRINT}"
  ```
  - **無簽現態**（`.asc`/pubkey 缺，或 `EXPECTED_SIGNING_FINGERPRINT` 未 pin）→ step **skip / `test -n` fail-closed**（不偽稱已簽、不盲信未 pin 之 key）；**有簽劣 / 簽章者 fingerprint 非 pinned（含 attacker-key-in-bundle 替換）/ pubkey 換**→`gpg` 非零或 `VALIDSIG` 不含 pinned fingerprint（`grep -q` 非零，`pipefail` 下 fail）→**fail-closed**；下游無 sentinel→skip。**綁簽章者（VALIDSIG）非檔首 key**——杜 codex[H2] multi-key 替換盲點。
  - **map-don't-recreate**：crypto 全由 native gpg；release_gate 仍 stdlib 結構 gate（precedent＝pip-audit/cyclonedx 之 subprocess 居 step）。無 masking（無 `|| true`/`set +e`）。reuse 既有 schedule/permissions/concurrency。
