### CP-1: enablement SSOT（docs/templates/security/enablement-matrix.json，source-only）

machine-readable 單一來源，據 README §Per-downstream enablement matrix + SAST/SBOM/release-integrity 三段表誠實提煉。

- **Schema**（明文於檔內 `_schema` 或 README）：
  ```json
  {
    "schema_version": 1,
    "description": "...non-certification caveat...",
    "dimensions": ["secret-scan", "sca", "sast", "sbom", "release-integrity", "disclosure"],
    "enablement_states": ["enforced-self", "opt-in-ci", "template-only-frozen", "local-precommit", "native-enforcing", "n-a"],
    "repos": {
      "council-forge": { "stack": "Python", "ci": "GitHub Actions (self)", "dimensions": { "<dim>": {"state": "enforced-self", "rationale": "..."} , ...} },
      "Sentinel":  { "stack": ".NET (frozen)", "ci": "Azure Pipelines", "dimensions": {...} },
      "LINE-BOT":  { "stack": ".NET (active)", "ci": "GitHub Actions", "dimensions": {...} },
      "Verso":     { "stack": "Tauri (Rust+Node)", "ci": "none", "dimensions": {...} },
      "Vero":      { "stack": "Tauri (Rust+Node)", "ci": "none", "dimensions": {...} }
    }
  }
  ```
- **受控詞彙**（enablement_states，據 §3 + README）：
  - `enforced-self`：council-forge 自身 security-scan.yml 已強制（pip-audit/secret/static/python-sast advisory/sbom/security-txt/release-integrity）。
  - `opt-in-ci`：可接 GitHub Actions（唯 LINE-BOT 活躍 remote）。
  - `template-only-frozen`：Sentinel 凍結期僅置 template、不接 CI、不動 azure-pipelines（解凍後自掛）。
  - `local-precommit`：無 remote（Verso/Vero），本地/pre-commit 跑。
  - `native-enforcing`：native 工具即機制（.NET Roslyn `TreatWarningsAsErrors`、Rust `clippy -D warnings`），build 已強制。
  - `n-a`：該營該維度不適用。
- **內容**：每營 6 維度之 state + 一句 rationale。誠實——不宣稱未啟用者為已啟用（Sentinel/Verso/Vero 之 CI-borne 維度標 template-only-frozen / local-precommit，非 enforced）。
- **source-only**：置 `docs/templates/security/`（整體 root-only，不入 template/、不 propagate、不入 EXACT_SYNC）。

## Risks

> 事前驗屍（Premortem）：Risk / Trigger / Detection / Mitigation / Severity。

R1
- Risk: **偽 conformance**——dashboard 因 mechanism 檔在下游即標 covered/enforced，謊報下游 SSDLC 達標（主公最忌之合規劇場）
- Trigger: 以「mechanism overlaid」逕等同「practice covered」；caveat 缺失；status 詞彙含混
- Detection: 雙審專查誠實性；CP-4 誠實性測（overlaid≠covered、恆印 caveat）；status 詞彙審
- Mitigation: **三軸誠實分類**（overlay≠enforced）；status 詞彙嚴分（`upstream-governed`/`overlaid`/`project-owned`/`drifted`/`not-propagated`/`not-overlaid`/`unmapped`，**無 "covered"、無 status-`n-a`**——n-a 唯居 declared 欄）；**恆印 non-certification caveat**（Markdown+JSON）；declared 標「intent 非 runtime」；dashboard **不改 practice status**
- Severity: blocking

R2
- Risk: **stale 誤讀**——dashboard 報「四營 0 P8 機制」被誤讀為 retrofit 失敗，而非「P8 前 retrofit、P8 層待 propagate」
- Trigger: 不區分 `not-propagated`（時序，待 propagate）與 `drifted`/`failed`
