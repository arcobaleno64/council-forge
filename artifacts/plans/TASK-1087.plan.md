## Risks

> 事前驗屍（Premortem）：Risk / Trigger / Detection / Mitigation / Severity。

R1
- Risk: **偽達標**——dashboard 以形之綠（guard WARN-free）冒充質之達標，誤導「舊工已達現行標準」
- Trigger: status 詞彙含「passed/conformant」裸稱；形之/質之未分；caveat 缺
- Detection: 雙審專查誠實性；CP-5 測（無裸 passed、caveat 恆印、qualitative-review-pending 須雙審）
- Mitigation: **形之/質之嚴分**；status 無裸「passed」（`current-bar`/`formal-delta`/`qualitative-review-pending`/`reviewed`）；**恆印 machine-green≠quality caveat**；質之達標唯經立即雙審（附 decision ref）方標 reviewed
- Severity: blocking

R2
- Risk: **疊床架屋**——重造 task 掃描 / guard 回跑 / dashboard 框架
- Trigger: 不 reuse repo_health/guard_status；另寫平行掃描
- Detection: 雙審 DRY；CP-2 import 證 reuse
- Mitigation: reuse `repo_health_dashboard` 之 discover_artifacts/load_status/parse_datetime + `guard_status_validator` CLI（回跑非重寫驗證）+ 承 ssdf_conformance 誠實範式；獨立 script 單一職責（時序標準 drift）
- Severity: blocking

R3
- Risk: **竄改舊 task 史**——back-audit 改舊 task 之 artifact
- Trigger: dashboard/重審誤寫舊 artifact
- Detection: CP-5 read-only 不變式測 + git diff（舊 task 檔未動）
- Mitigation: dashboard **read-only on artifacts**（唯讀掃描 + 回跑 guard，不寫舊檔）；重審結論落**新** decision（不改舊 task 史）；bounded subprocess 限 guard_status
- Severity: blocking

R4
- Risk: **升標表失準**——漏/錯事件日，致時序對標誤判
- Trigger: 事件日臆測非實證；漏關鍵升標
- Detection: 雙審；CP-1 每事件附 commit ref（git log date 實證）
- Mitigation: 每事件 **date 據 git log commit date / decision 日期實證**（非臆測）+ TASK/commit ref；涵主公點名者 + 早期；schema 驗必備欄
- Severity: blocking

R5
- Risk: **立即重審 scope 蔓延 / 變重做**——N 太大、或重審變重新實作舊 task
- Trigger: 選太多 task；重審越界改舊碼
- Detection: 雙審；CP-4 N=3 界定；重審唯**判**質之 delta（不改舊碼）
- Mitigation: **N=3（plan 界定）**；重審＝以雙審**判**質之 delta（落 decision），須補者立 follow-up backlog**不在本 task 修**（逐批）；不改舊 task 碼
- Severity: blocking

R6
- Risk: **重審不誠實**——為清白粉飾（漏報質之 delta）或過苛（以今日 bar 苛責舊 task 為失敗）
- Trigger: 重審結論未附雙審證據；或以現行 bar 否定舊 task 之歷史有效性
- Detection: 立即重審之 codex+gemini 雙審（他查）；decision 附證據
- Mitigation: 重審結論**附雙審證據 + bar/when/review**；**誠實雙向**——舊 task 於其完成時 bar 有效（非失敗），唯標今日 bar 之質之 delta（若有）為 forward backlog；不粉飾、不過苛
- Severity: blocking

R7
- Risk: **形之 delta 解析脆**——guard_status WARN 輸出格式變致解析誤
- Trigger: 硬編 WARN 字串解析；guard 輸出改
- Detection: CP-5 測（mock guard_status 多種 WARN 輸出）
- Mitigation: 解析以 `[WARN]`/`[FAIL]` 前綴 + exit code（穩定介面）；測涵多 WARN 樣態；guard 輸出改則測捕
- Severity: non-blocking

R8
- Risk: **母本退 / cov 不足**——新 script 未 100%、workflow-guards 漂移
- Trigger: 漏測；root/template 不同步
- Detection: 完整 cov gate；母本 guard chain；byte-identity
- Mitigation: dashboard 100% cov；workflow-guards root+template byte-identical（改則重生 manifest）；source-only 不入 EXACT_SYNC；母本 guard 守
- Severity: non-blocking

R9
- Risk: **時序對標誤判（codex[crit]+[H1]）**——日期粒度失同日序（2026-06-07 密集升標），或完成時間裸用 status.last_updated（含後來 repair/waiver edit）致 task 誤判已/未經某標準
- Trigger: YYYY-MM-DD 比較；裸用 status.last_updated 為完成時間
- Detection: 雙審；CP-5 測（ISO instant 比較、同日序、完成時間多源 + unknown fail-closed）
- Mitigation: **D1 ISO 8601 instant** 比較（`%cI`，非 date）；**D2 完成時間多源**（verify/decision/git %cI，記 source）+ 無可靠源→`completion-unknown` fail-closed（不臆測對標）
- Severity: blocking

R10
- Risk: **read-only 破——回跑 guard 誤觸 mutating mode 改舊 artifact（codex[M1]）**
- Trigger: guard_status_validator 傳 --auto-classify/--reconcile/--write-transition 等 mutating flag
- Detection: CP-5 **hash before==after 不變式**測；bounded argv allowlist 測
- Mitigation: **D4——回跑唯 `--task-id`（non-mutating allowlist，禁 mutating flag）**；測舊 artifact hash before/after 不變；bounded subprocess（限 guard_status_validator 單一 read-only 介面）
- Severity: blocking

## Validation Strategy

(a) CP-1 升標表 SSOT（每事件 git-log 實證 date + ref；schema 驗）→ (b) CP-2 dashboard（reuse repo_health/guard_status；時序對標 + 形之 delta 回跑 + 風險分類 + 質之 backlog；恆印 caveat；read-only）→ (c) CP-3 全舊 task 形之 delta 收集 → (d) CP-4 立即重審 top-3 最高風險（codex+gemini 雙審重判質之 delta，誠實落 decision）→ (e) CP-5 測（誠實性 + 時序對標 + 形之解析 + read-only 不變式；100% cov）+ 持續監看 → (f) 完整 cov gate ≥90 + 母本 guard chain 綠 + workflow-guards byte-identical + 舊 task artifact 未竄改 → (g) **plan 雙審皆無 blocking/critical**（+ 動工後 dashboard/重審之 working-tree 實作層雙審）→ (h) commit（本地、未 push）。
