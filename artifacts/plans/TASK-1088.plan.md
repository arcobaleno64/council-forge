## Proposed Changes

### CP-1: read + traversal fail-closed on genuine I/O failure（D1）
- 新 `class ScanReadError(RuntimeError)`——in-scope 檔之 traversal/stat/read 遇 OSError = fail-closed coverage 失敗。
- `read_text(path)`：`OSError` → **raise ScanReadError**（附 path）；oversize（`> MAX_FILE_BYTES`）/ NUL（`b"\x00" in raw[:4096]`）→ 維 `return None`（deliberate 非文本 skip）。docstring 界明二分：**failure→raise（fail-closed）vs deliberate non-text skip→None**。
- **`iter_repo_files(root)` traversal/stat fail-closed（D1）**：檔案列舉改 fail-closed——`os.walk(root, onerror=_raise)`（`_raise` 將 OSError 轉 ScanReadError），或 `sorted(root.rglob("*"))` materialize 包 try/except OSError→ScanReadError（**憑實測定**：先驗 3.14 之 rglob 對不可讀 dir 是否 raise；若靜默吞則用 os.walk(onerror)）；`is_text_candidate`（純 suffix 檢，無 I/O）後 `path.is_file()` 包 try/except OSError→ScanReadError。杜「檔未列舉即靜默→exit 0」。
- `scan_secrets`/`scan_static`/`scan_sast`：**加向後相容 `*, skipped: list[str]|None = None`（D3）**；`text is None`（合法 skip）→ 若 skipped 非 None append rel_path，續 continue；ScanReadError 自 read_text/iter_repo_files 上拋（不捕）。

### CP-2: main fail-closed on bad root + I/O error + surface skips（D2/D3/D4）
- `main`：`root = Path(args.root).resolve()`；**`if not root.is_dir(): print("[FAIL] scan root does not exist or is not a directory: {root}", file=sys.stderr); return 2`**（dispatch **前**）。
- `skipped: list[str] = []`；dispatch（secrets/static/sast 皆傳 `skipped=skipped`）整體包 **`try/except ScanReadError`（確包 sast 分支，於 `emit_sast` 之前，D2）**：捕 → `print("[FAIL] scan aborted — I/O error reading an in-scope file: {exc}", file=sys.stderr); return 2`。
- 掃描後（成功）：`if skipped: print("[INFO] {len} file(s) skipped (oversize/binary, not text-scanned): {skipped}", file=sys.stderr)`（D3，可審不靜默）。
- exit code 語意明文於 docstring：**0 clean / 1 findings / 2 scan-error·bad-root（fail-closed）**。**明辨訊息（D4）**：scan-error `[FAIL] scan aborted — I/O error...`(exit 2) vs findings `[FAIL] Detected N finding(s)`(exit 1)。secrets/static gating 不變（CI exit≠0 fails，含 2）。

### CP-3: 測 + EXACT_SYNC + release-manifest
- `test_security_scans.py`（root+template byte-identical）：
  - 改 `test_read_text_guards`：missing（OSError）→ `pytest.raises(ScanReadError)`（非 None）；binary/oversize → None（不變）。
  - 補（D1）：read_text OSError raises；**iter_repo_files traversal/stat OSError → ScanReadError**（monkeypatch os.walk/rglob 或 is_file raise）。
  - 補（D2）：`main` 於 secrets+static+**sast** 三路徑各遇 ScanReadError → exit 2（monkeypatch read_text raise；sast `--format sarif` 亦 2，不 advisory 0）。
  - 補（D3）：oversize/NUL skip → main 印 `[INFO] ... skipped`（skipped 累計）；scan_*(skipped=[]) 收 rel_path。
  - 補：`main(["--root", nonexistent, "secrets"])==2` 印 [FAIL]；clean→0；findings→1。
  - 保 `test_skips_when_read_text_returns_none`（oversize/NUL None→skip 仍效）+ test_repo_security_scan_sast 全綠。

## Risks

> 事前驗屍（Premortem）：Risk / Trigger / Detection / Mitigation / Severity。

R1
- Risk: **誤殺合法 skip**——將 oversize/NUL（既定非文本 scope 限）誤改為 hard-fail，致正常 repo（含大型 lockfile / minified asset / binary-suffixed-as-text）CI 恆紅
- Trigger: read_text 對 oversize/NUL 亦 raise
- Detection: 雙審；CP-3 測（oversize/NUL→None 仍 skip，不 raise）
- Mitigation: **嚴分二態**——OSError→raise（fail-closed）；oversize/NUL→return None（deliberate skip，docstring 界明 MAX_FILE_BYTES DoS 守 + binary 守為既定 scope）；測釘死二態
- Severity: blocking

R2
- Risk: **fail-open 未真閉**——main 漏捕 ScanReadError 某路徑（如 sast），或 root 檢可繞，仍能靜默 exit 0
- Trigger: try/except 範圍不全；root 檢於 resolve 後遺漏；sast 路徑早 return 未包
- Detection: 雙審；CP-3 測（secrets+static+sast 三路徑各觸 ScanReadError→2；nonexistent root→2）
- Mitigation: try/except 包**全** dispatch（含 sast）；root.is_dir() 檢於 dispatch **前**；測三 command 各驗
- Severity: blocking

R3
- Risk: **EXACT_SYNC 破**——root 改而 template/ 漏同步（或反），guard_contract byte-identity 紅
- Trigger: 唯改 root 未鏡 template
- Detection: guard_contract（EXACT_SYNC byte-identity）；CP-3 byte-identical 核
- Mitigation: repo_security_scan.py + test_security_scans.py root↔template **byte-identical**；改 template/ → release-manifest 重生
- Severity: blocking

R4

- Trigger: skip 無計數/報告

- Severity: non-blocking
