## Proposed Changes

### CP-1: 驗證函式於 github_publish_common.ps1（可獨測）
- **真 repo root（D1）**：`Get-RepoRoot` helper——`git rev-parse --show-toplevel`（publish-release 本即依賴 git）取真根；gate/manifest 路徑皆用真根（**非** `Split-Path -Parent $scriptDir`＝artifacts/）。
- **`Invoke-ReleaseIntegrityGate -RepoRoot -ScriptDir`（鏡 CI 完整 integrity，D2）**：① `python <ScriptDir>/snapshot_manifest.py verify --template-root <RepoRoot>/template --manifest <RepoRoot>/.well-known/release-manifest.json`（tree↔manifest 一致，捕 stale drift）；② `python <ScriptDir>/release_gate.py --file <RepoRoot>/.well-known/release-manifest.json --format checksums`（結構：schema/algo/digest/min-entries）。任一 `$LASTEXITCODE -ne 0` → throw（fail-closed）。
- **`Get-SigningTriadState -RepoRoot`**：回 triad present 計數 + 各成員狀態——pinned `$env:EXPECTED_SIGNING_FINGERPRINT`、detached `<RepoRoot>/.well-known/release-manifest.json.asc`、public `<RepoRoot>/.well-known/release-signing.pub`。
- **`Assert-ReleaseSignature -RepoRoot`**（鏡 CI security-scan.yml release-integrity job）：
  - triad **零 present** → 未 provisioned → 回 `'unprovisioned'`（skip 簽章驗；log；結構 gate 仍守）。
  - **任一 present → ARMED**：三者**俱全**否則 throw（fail-closed——移除 sig/pub/unset pin 不能靜默停用）；pin 正規化大寫 + **嚴驗 40-hex**（`^[0-9A-F]{40}$`，杜弱/regex-metachar pin）；isolated `GNUPGHOME`（mktemp）`gpg --batch --import <pub>`；**capture-then-check**：`$status = gpg --batch --status-fd 1 --verify <sig> <manifest>`（`$LASTEXITCODE` 直檢，非 pipe）；**exact-field-equality** 綁 pinned signer——VALIDSIG 行之 `$3` 或 `$NF == want`（非 substring/regex）；不符 → throw。回 `'verified'`。

### CP-2: publish-release.ps1 preflight 耦合（於 WhatIf-exit 前）
- **真根（D1）**：`$releaseRoot = Get-RepoRoot`（git rev-parse；**非**既有誤名之 `$repoRoot`＝artifacts/）；二驗證 step 之 manifest/triad 路徑皆用 `$releaseRoot`。既有 `$repoRoot`（git/owner-repo 用，git 自子目錄上溯故無誤）不動。
- preflight step **1g（integrity）**：`Invoke-ReleaseIntegrityGate -RepoRoot $releaseRoot -ScriptDir $scriptDir`（snapshot_manifest verify + release_gate）；catch → `Write-Error` + `exit $EXIT_PRECONDITION_FAIL`。
- preflight step **1h（signature，D4 fail-closed-by-default）**：`try { $sigState = Assert-ReleaseSignature -RepoRoot $releaseRoot } catch { Write-Error ...; exit $EXIT_PRECONDITION_FAIL }`（catch＝**ARMED-fail**，恆中止、**`-AllowUnsigned` 不 catch**）；then：
  - `'verified'` → `[OK] release signature verified`。
  - `'unprovisioned'` → **預設 FAIL CLOSED**（`Write-Error "release signing not provisioned; pass -AllowUnsigned to publish unsigned, or provision signing"`; `exit $EXIT_PRECONDITION_FAIL`）；**唯 `-AllowUnsigned`** → `Write-Warning "[WARN] publishing UNSIGNED release per explicit -AllowUnsigned"` 放行。
  - **`-AllowUnsigned` switch（新 param）**：唯放行 **unprovisioned（triad 零）** 之未簽發布（operator 顯式 opt-in，loud-logged）；對 **integrity-gate-fail** 與 **ARMED-fail** 一律**無效**（恆中止）。
- 二步置於 `=== Preflight PASSED ===` / `if ($WhatIf)` early-exit **之前**，故 `-WhatIf` 仍跑全驗證、僅略過 `gh release create`（可測、不需真 gh create）。

### CP-3: 測 + byte-identity + manifest
- `test_publish_release_verify.py`（pytest，dot-source pwsh 函式直測）：
  - `Invoke-ReleaseIntegrityGate`：valid manifest → 無 throw；tampered/malformed manifest → throw（exit≠0）。
  - `Get-SigningTriadState` / `Assert-ReleaseSignature`：triad 零→`unprovisioned`；ARMED-incomplete（僅 pin / 僅 .asc）→ throw；非-40-hex pin → throw。
  - **gpg-gated**（`shutil.which('gpg')`，否則 skip，仿 test_release_signing.py）：真 keygen→detach-sign→`Assert-ReleaseSignature` with pinned fpr → `verified`；tamper manifest → throw；wrong-fingerprint pin → throw（exact-equality 綁定）。
- byte-identity：publish-release.ps1 + github_publish_common.ps1 root↔template；release-manifest 重生（若涉）+ verify exit 0；完整 cov gate ≥90（.ps1 非 Python cov；測為 integration，∈ omit 視需）。

## Risks

> 事前驗屍（Premortem）：Risk / Trigger / Detection / Mitigation / Severity。

R1
- Risk: **fail-open 簽章**——ARMED 後移除 sig/pub 或 unset pin 致簽章驗證靜默停用、發布未簽 release
- Trigger: 以「檔存在」決定是否驗（如 `if .asc exists`），刪 .asc 即 skip
- Detection: 雙審；CP-3 測（ARMED-incomplete→throw）
- Mitigation: **鏡 CI triad armed-vs-unprovisioned**——任一 present 即 ARMED、三者俱全否則 fail-closed（非以單一檔存在決定）；測釘死 ARMED-incomplete→中止
- Severity: blocking

R2
- Risk: **簽章繞過（弱 pin / substring 綁定）**——regex-metachar pin（`.*`）或 substring 比對致任何 good signature（攻擊者 key）被接受
- Trigger: pin 未驗 40-hex；VALIDSIG 以 substring/regex 比對
- Detection: 雙審；CP-3 測（非-40-hex pin→throw；wrong-fingerprint→throw）
- Mitigation: **40-hex 嚴驗 + exact-field-equality**（$3 或 $NF == want，非 substring）；capture-then-check（gpg rc 直檢非 pipe）——鏡 CI
- Severity: blocking

R3
- Risk: **誤殺 bootstrap / 既有 preflight 回歸**——未 provisioned 即阻所有發布，或動到既有 gh/auth/tag/dup preflight 致回歸
- Trigger: 驗證步驟誤置/誤改既有 gh/auth/tag/dup 步驟；或 unprovisioned 無 opt-in 即阻 bootstrap
- Detection: 雙審；CP-3 測（unprovisioned 無/有 -AllowUnsigned；既有 preflight 不動）
- Mitigation: **D4**——unprovisioned（triad 零）預設 fail-closed，唯顯式 `-AllowUnsigned` opt-in 放行（operator 一次性 conscious choice，不破 bootstrap，合 release-signing.md operator-gated 殘留；結構 integrity gate 恆守）；驗證步驟**新增**於既有 preflight 後、WhatIf-exit 前，不改既有步驟
- Severity: blocking

R4
- Risk: **byte-identity 破**——publish-release.ps1/github_publish_common.ps1 root↔template 不同步
- Trigger: 唯改 root 未鏡 template
- Detection: guard_contract（byte-identity）；CP-3 byte-identical 核
- Mitigation: 二 .ps1 root↔template byte-identical；改 template → release-manifest 重生（若涉）
- Severity: blocking

R5
- Risk: **integrity gate 未真耦合**——驗證步驟置於 `gh release create` 後、或 WhatIf-exit 後，致實發布前未驗
- Trigger: 步驟順序誤
- Detection: 雙審；CP-3（-WhatIf 跑驗證；integrity-fail→中止於 create 前）
- Mitigation: 二驗證步驟置 preflight 內、WhatIf-exit **前**、`gh release create` **前**；測證 -WhatIf 仍觸驗證
- Severity: blocking

R6
- Risk: **pwsh↔bash 範式移植誤弱化簽章授權（v1 codex high→blocking）**——CI bash awk/gpg status 解析移植 pwsh 走樣（field split、case、status-fd、native `$LASTEXITCODE`），致弱化 signer 綁定（接受 attacker-key-in-bundle / wrong-fp）
- Trigger: pwsh 解析 VALIDSIG 行與 bash awk 語意不一；gpg native 後未即檢 `$LASTEXITCODE`
- Detection: 雙審；gpg-gated CP-3 測（field-mapping、**attacker-key-in-bundle**、wrong primary/signing fp、capture-then-check rc）
- Mitigation: pwsh 以 `-split`/逐行嚴復 awk 之 `$1=='[GNUPG:]' && $2=='VALIDSIG' && ($3==want || $NF==want)`；`gpg` native 後**即** `$LASTEXITCODE` 檢（capture-then-check，非 pipe）；gpg-gated 真測證語意等價（含 attacker-key 仍 exact-fp 拒）
- Severity: blocking

R7
- Risk: **RepoRoot 謬致 gate 恆敗（v1 codex blocking）**——`Split-Path -Parent $scriptDir`＝`artifacts/`，gate 讀 `artifacts/.well-known/release-manifest.json`（不存），valid release 亦 fail-closed 恆敗、誤導 bootstrap
- Trigger: 沿用既有誤名 `$repoRoot`（artifacts/）作 manifest 路徑
- Detection: 雙審；CP-3 `-WhatIf` 測（證讀真根 `.well-known`）
- Mitigation: **D1**——`Get-RepoRoot`（git rev-parse --show-toplevel）取真根；驗證路徑用真根；`-WhatIf` 測釘死路徑解析
- Severity: blocking
