## Proposed Changes

### CP-1: detect_changed_files is_repo + per-probe errors；validate_prompt_case_sync 三分（D1/D2）
- **detect_changed_files** 改回 `(is_repo: bool, changed: set[str], errors: list[str])`：
  - 先 `git rev-parse --is-inside-work-tree`：`FileNotFoundError`（git 缺）或非零/非 "true"（非 work tree）→ `return (False, set(), [])`（**非-git bootstrap**，含 scaffold git_init=False）。
  - is_repo=True：逐 probe（`diff --name-only HEAD` / `diff --name-only --cached` / `ls-files --others --exclude-standard`）跑；`returncode != 0` → `errors.append(f"{cmd}: exit {rc}")`；成功則收 changed token。
  - `return (True, changed, errors)`。
- **validate_prompt_case_sync** 三分（D1/D2）：
  - `if not is_repo: return []`（**非-git bootstrap**：無 change-baseline，prompt-sync N/A；docstring 明標 deliberate-documented 分支，非靜默 fail-open——合 scaffold downstream greenfield/tarball）。
  - `if errors: return ["Cannot verify prompt-contract sync: git change-detection degraded (probe failed: ...). Refusing to pass silently (TASK-1090 fail-closed)."]`（**git repo 但任一 probe 敗 = 部分降級**，fail-closed；杜 B2）。
  - `if not changed: return []`（git repo、全 probe 成、無變更 = legit）。
  - 餘維既有（prompt entry 改而無 regression → error）。

### CP-2: detect_raci_violations superseded docstring（Part 2，doc-only）
- 加 docstring 明：**LEGACY / superseded**——本函式無 runtime caller；live RACI 強制路徑為 `classify_path` + `--audit-raci`（其對 unknown path fail-close，見 guard_status_validator 之 v2 audit）；本函式之 unmatched→`code` 預設對真 code source（非 artifact）為**正確**分類，唯保留作歷史/測試參照。**不變行為**（改之反致真 code 檔誤判為 violation，且其為 dead code）。

### CP-3: 測 + EXACT_SYNC + release-manifest
- `test_guard_contract_validator.py`（root+template byte-identical；monkeypatch 全改回 **3-tuple** `(is_repo, changed, errors)`）：
  - **detect_changed_files subprocess-mock 直測（D3/D5，落 test_guard_status_validator_state.py 之 `TestDetectChangedFiles` 類，已 mock subprocess）**：mock `subprocess.run`——`git rev-parse` FileNotFoundError→`(False,set(),[])`；rev-parse 非零→`(False,...)`；is_repo=True 三 probe 全成→`errors==[]`；is_repo=True 一 probe rc≠0→`errors` 非空。既有 TestDetectChangedFiles 諸測（691/699/717/731/744）升 3-tuple unpack。
  - **validate_prompt_case_sync 三分**：`(False,set(),[])`（非-git bootstrap）→`[]`（legit，非 error）；`(True,set(),["probe fail"])`（**部分降級**）→**1 fail-closed error**；`(True,set(),[])`→`[]`；`(True,{CLAUDE.md},[])`→1 error；`(True,{CLAUDE.md, regression},[])`/`(True,{guard_status.py},[])`→`[]`。
  - 更新既有四測之 monkeypatch 為 3-tuple（語意：原 `test_no_git_available`→非-git bootstrap 回[]；餘 True 分支補空 errors）。
  - detect_raci_violations 既有測（行為不變，Part 2 doc-only）全綠。
