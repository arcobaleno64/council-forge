## Uncertain Items

## Constraints For Implementation

- CI-1: 拆出之 submodule 須與既有 import path 後向相容；策略為「主檔 re-export」（即原 `from guard_status_validator import X` 仍可解析，因 X 在主檔以 `from .helpers import X` 形式 re-export）。
- CI-2: pytest 通過數不得減於 1166；coverage 不得低於 90%。
- CI-3: 不可改變任何 CLI 旗標、輸出格式、exit code。
- CI-4: 不可刪除任何函式 / class / case；拆分 = 移動 + import re-export，不含刪除。
- CI-5: cases 外部化（若採行）須保 build_cases() 之輸出結構與順序與拆分前等同。
- CI-6: template/ 須完整鏡像；SHA-256 root↔template 一致。
