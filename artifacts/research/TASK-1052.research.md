## Confirmed Facts

- CF-1: Claude Code project-level slash command 為 `.claude/commands/<name>.md`，frontmatter 採 YAML，常見 keys：`description`（一句話用途）、`argument-hint`（user 鍵入 `/cmd ?` 時提示）、`allowed-tools`（限制可呼叫工具）。主體為純 markdown 自然語言指引，由 Claude 解讀執行（同 `.github/skills/` SKILL.md 風格）。Inline citation: [1] Anthropic Claude Code docs "Slash commands"。
- CF-2: `Invoke-CodexAgent.ps1` 之 param block（行 14-42）含 8 個既有參數 + TASK-1057 新加 2 參數（`-AllowedPaths` / `-AutoRestore`）。`-Model` + `-ModelPolicy fixed` 組合可固定 dispatch 至特定 model（Get-TaskScaleProfile 之 fallback ladder 將被覆寫為單一 model）。stdin pipe 模式於 line 131：`$null | & $Executable $processArgs 2>&1`——目前並非 stdin pipe，prompt 仍為 positional arg（cmd 8191 限制屬 TASK-1053 bug）。Inline citation: [2] `artifacts/scripts/Invoke-CodexAgent.ps1` 行 14-42（params）+ 行 130-145（執行 block）。
- CF-3: Council-of-models 風格之內部源為 `.github/skills/quality-playbook/SKILL.md` File 5 §RUN_SPEC_AUDIT.md「Council of Three」段：「Three independent AI models audit the code against specifications. Why three? Because each model has different blind spots — in practice, different auditors catch different issues.」protocol 含「audit prompt with guardrails」「triage process（merge findings by confidence level）」「fix execution rules（small batches by subsystem）」。本批 `/codex-review` 為 Council 之單機 Codex 變體（3 model tier 替代 3 model family），triage 邏輯落 Claude slash command 端自然語言指引。Inline citation: [3] `.github/skills/quality-playbook/SKILL.md` 行 284-291（File 5 描述）。
- CF-4: `git diff` 之 PowerShell 端常見模式：(a) `git diff` for unstaged；(b) `git diff --cached` for staged；(c) `git diff HEAD` for both staged + unstaged；(d) `git diff <ref>` for commit range。本批 `-DiffSource` 之 4 值映射：`staged → diff --cached` / `unstaged → diff` / `all → diff HEAD` / `HEAD → diff HEAD~1 HEAD`（最近一 commit）。Inline citation: [4] git docs "git-diff" + `artifacts/scripts/Invoke-CodexAgent.ps1` 行 130（`& $Executable` 模式）為 PowerShell 端 process invocation 之既定 pattern。
- CF-5: Codex CLI `exec` mode 之 prompt 仍以 positional arg 方式接收（per Invoke-CodexAgent.ps1 行 122 `$processArgs += $Prompt`）；cmd.exe shell 啟動前之 args 總長度上限 8191 字（Windows 內建限制，TASK-1053 已記錄）。本批 `Invoke-CodexReview.ps1` 為了避開該限制，prompt 設計為「短 instruction（<500 字）+ stdin pipe diff」結構：dispatch 時將 diff 內容透過 PowerShell pipeline 餵給 Codex（詳見 plan §Step 2）。Inline citation: [5] auto-memory `project_followup_codex_wrapper_gpt55.md` §A.1（cmd.exe 8191 限制 + stdin pipe workaround）+ `artifacts/scripts/Invoke-CodexAgent.ps1` 行 122。
