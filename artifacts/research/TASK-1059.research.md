## Uncertain Items

- UNVERIFIED: `git stash push -u` 對 ignored 檔（`.gitignore` 內 entries）之行為；man page 稱「不含 ignored」但本 task 之 dispatch 環境是否觸發此邊界未知。Mitigation: smoke (i) 之 mock repo 以 `.gitignore` 排除 `.obsidian/` 之類典型 untracked + ignored 檔；若行為與假設不符，於 plan 階段補 `--no-include-ignored` flag 或 `git stash push -u --keep-index` 之變體。
- UNVERIFIED: PowerShell 之 `& git stash pop` 對 conflict exit 1 之 `$LASTEXITCODE` 可靠性；man page 稱 conflict exit 1 但本 wrapper 之 caller invocation chain（pwsh → git.exe via cmd.exe）可能 mask exit code。Mitigation: smoke (iv) 直接驗證 conflict 情境之 `$LASTEXITCODE`；若不可靠則改 parse `git stash pop` stdout 之 conflict marker 字串。
- UNVERIFIED: `git stash list --max-count=1` 在 stash entry 為 0 時之 stdout 是否完全空 vs 一空白行；可能影響 `Save-PreDispatchState` 之 ref capture 邏輯。Mitigation: 以 `[string]::IsNullOrWhiteSpace()` 對 capture 結果防呆。
- UNVERIFIED: 兩 wrapper 之 helper function 是否可放於 ps1 file 之 top（param block 之後 / main loop 之前）；既有 `Test-PathInAllowed` 為 inline lambda-style 之 single-use helper，置於 guard if-block 之前；本 task 之 3 helper 為 cross-section reuse，建議集中於 param block 之後成獨立 region。Mitigation: plan 階段確認 ps1 之 function scope 規則（PowerShell 之 function 須在 invocation 之前定義）。

## Constraints For Implementation

- CI-1: `Save-PreDispatchState` 必須處理 `git stash push` 之 4 case：(a) working tree clean → 不 stash，return null ref；(b) 有 modifications → stash 成功，return ref；(c) `git stash` 失敗（如 lock conflict）→ Write-Host warning + abort dispatch + exit 4（不得 silent degrade 至既有破壞性 mode）；(d) `git stash list` ref capture 失敗 → return null + 同 (c) 處理。
- CI-2: `Restore-PostDispatchDelta` 必須僅對 `$violations` 集合之 path 操作；不得對全 repo 跑 `git checkout HEAD --` 或 `git clean -fd`；error handling 對 `git ls-files --error-unmatch` 之 exit code 區分 tracked / untracked，與既有邏輯一致。
- CI-3: `Pop-PreDispatchState` 必須處理 3 case：(a) ref 為 null（無 stash）→ no-op return 0；(b) `git stash pop` 成功 exit 0 → return 0；(c) conflict exit 1 → 印 stash@{N} ref + 不 drop + return 3。Conflict 不得 silent retry。
- CI-4: 兩 wrapper 之 helper function 命名空間獨立；本 task 之 3 helper 名 `Save-PreDispatchState` / `Restore-PostDispatchDelta` / `Pop-PreDispatchState` 為唯一；既有 `Test-PathInAllowed` 不改名。
- CI-5: `-AutoRestoreLegacy` switch 之語意：caller 傳此 flag 時 wrapper 在 invoke `Save-PreDispatchState` 之前印 `[DEPRECATED] -AutoRestoreLegacy maps to -AutoRestore for backward-compat; expect removal in TASK-10xx (date TBD)` (DarkYellow)，並 forward 邏輯等同 `-AutoRestore $true`；不同時並用 `-AutoRestore` 與 `-AutoRestoreLegacy`（若同時設 → 印 warning + 取 `-AutoRestore` 之值）。
