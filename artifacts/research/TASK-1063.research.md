## Confirmed Facts
- Q1: `ubuntu-latest` is the standard for GitHub Actions CI pipelines (https://docs.github.com/en/actions/using-github-hosted-runners/about-github-hosted-runners/about-github-hosted-runners). PowerShell 7 is pre-installed on `ubuntu-latest` (https://docs.github.com/en/actions/using-github-hosted-runners/about-github-hosted-runners/about-github-hosted-runners#supported-runners-and-hardware-resources). `windows-latest` also supports PowerShell 7 but carries higher per-minute billing costs than Ubuntu (https://docs.github.com/en/actions/administering-github-actions/usage-limits-billing-and-administration#billing-for-github-actions).
- Q2: OpenAI API pricing is based on tokens per 1 million units (https://openai.com/api/pricing). Rate limits are defined by TPM (Tokens Per Minute) and RPM (Requests Per Minute) (https://platform.openai.com/docs/guides/rate-limits/usage-tiers).
- Q3: The canonical SHA for `actions/github-script@v7.0.1` is `60a0d83039c74a4aee543509d22c19323f46f366` (https://github.com/actions/github-script/releases/tag/v7.0.1). Permissions required to commit to branches or open PRs via `GITHUB_TOKEN` include `contents: write` and `pull-requests: write` (https://docs.github.com/en/actions/security-guides/automatic-token-authentication#permissions-for-the-github_token).
- Q4: The default `-CouncilModels` in `artifacts/scripts/Invoke-CodexReview.ps1` is defined at line 55: `[string[]]$CouncilModels = @('gpt-5.4-mini','gpt-5.4','gpt-5.5')` (artifacts/scripts/Invoke-CodexReview.ps1:55). This covers the user's intended tier count (3), though the user specified `gpt-5-mini` while the code uses `gpt-5.4-mini`.
