## Confirmed Facts

- F-1: `Invoke-CodexAgent.ps1` param 區段含 `[Parameter(Mandatory=$true)] [string]$Prompt`（artifacts/scripts/Invoke-CodexAgent.ps1:15-16），無 path-reference 替代 param；另含 `[ValidateSet("tiny", "docs-only", "standard", "high-risk", "cross-module", "critical", "security", "architecture")] [string]$Tier`、`[ValidateSet("auto", "fixed", "fallback")] [string]$ModelPolicy`、`[switch]$AutoRestore = $false`、`[switch]$AutoRestoreLegacy = $false`、`[switch]$IncludeLifecycleInBaseline = $false`（per artifacts/scripts/Invoke-CodexAgent.ps1:15-40）。
- F-2: `Invoke-GeminiAgent.ps1` param 區段含 `[Parameter(Mandatory=$true)] [string]$Prompt`（artifacts/scripts/Invoke-GeminiAgent.ps1:14-15），param 結構與 Codex wrapper 同形（per artifacts/scripts/Invoke-GeminiAgent.ps1:14-40），無 path-reference 替代。
- F-3: `Invoke-CodexReview.ps1` 不收 `-Prompt`，改收 `[ValidateSet('staged','unstaged','all','HEAD')] [string]$DiffSource = 'all'`、`[string]$OutputDir`、`[string]$ReasoningEffort = 'high'`、`[switch]$DryRun = $false`、`[switch]$AutoRestore = $false`、`[switch]$ShowHelp = $false`（per artifacts/scripts/Invoke-CodexReview.ps1:49-64）；review wrapper 之 prompt 由 diff source 自動推導，不存在 caller-side 自由文字 prompt anti-pattern。
- F-4: Caller-side dispatch prompt 走 Claude Code Agent tool 之 tool call `prompt` field；該 field 為主 agent generation output，必經主 agent context；token 成本 = 主 agent input + tool-call composition + sub-agent input（per `memory/feedback_dispatch_prompt_discipline.md` line 7-9）。Fresh sub-agent（如 Gemini wrapper / Codex wrapper / 多數 named subagent_type）為 fresh session 全載，無 prompt cache 攤銷（per memory line 9）。
- F-5: TASK-1063 之 Gemini dispatch prompt 為 5722 chars，主 agent 已吞下整段；同 dispatch 之 Gemini 回應 Sources 段含捏造 GitHub URL（per `memory/feedback_wrapper_known_bugs.md` Bug-B1，Gemini Sources fabrication 已知行為）。事件記錄：`artifacts/decisions/TASK-1062.decision.md` 含 `5722-char prompt 縮為 8 chars [ROLE]`。
- F-6: TASK-1061 之 Codex dispatch prompt 為 5001 chars multiline；走 native arg 路徑（`& codex.cmd -p $Prompt`）；Windows `cmd.exe` 對 multiline arg 在第一個 LF/CR 處截斷，codex CLI 收到 prompt 第一行 `[ROLE]`（per `artifacts/code/TASK-1061.code.md` § Coding 段；`artifacts/research/TASK-1062.research.md` F-5）。此為 Bug-W4 之 deterministic 觸發案，9 retry × 3 tier 全失敗。
- F-7: TASK-1062 commit `b5b7e32` 已將 stdin pipe threshold 由 7000 降至 0（即 stdin 永遠走 stdin pipe；Codex side，per artifacts/scripts/Invoke-CodexAgent.ps1），TASK-1063 reopen pass 補 Gemini 同 fix（per artifacts/scripts/Invoke-GeminiAgent.ps1）；wrapper-side multiline 截斷之 root-cause 已解。但 caller-side 之 token 成本問題（F-4）未受影響——wrapper fix 修的是 CLI arg 鏈路，非主 agent context 之 token attribution。
- F-8: `EXACT_SYNC_FILES` 名單之 source-of-truth 為 `artifacts/scripts/guard_contract_validator.py:18-61`（41 條 entries；非 `workflow_constants.py`）；guard_contract_validator 之 `for relative in EXACT_SYNC_FILES`（line 402）即 SHA-256 mirror 強制檢查 loop。
