## Confirmed Facts

- F-1: Invoke-CodexAgent.ps1 之 $Prompt 為 mandatory string param（artifacts/scripts/Invoke-CodexAgent.ps1:15-17）；無 DryRun mode；param 區段定義於 line 15-51（51 行）。Invoke-GeminiAgent.ps1 同 pattern（per artifacts/scripts/Invoke-GeminiAgent.ps1:14-40）。
- F-2: Invoke-CodexReview.ps1 不收 $Prompt；$reviewInstruction 由 $diffText + 固定模板組成（artifacts/scripts/Invoke-CodexReview.ps1:116-133），$promptSize = $reviewInstruction.Length 計於 line 134。DryRun mode 已存（line 154-155 印 `[DRY-RUN] dispatch: prompt_size=$promptSize`）。
- F-3: 既有 wrapper exit code 分配：0=success / 1=API failure（dispatch wrapper 之 RetryPatterns 耗盡）/ 2=scope guard violation（AllowedPaths 寫越界）/ 3=git diff failed（review wrapper line 106）。Exit code 4+ 為可用，本 task 採 4 為 bounds-check reject 之 exit code（per artifacts/scripts/Invoke-CodexReview.ps1）。
- F-4: 既有 wrapper-level pytest 採 fake-exe pattern via `run_wrapper` fixture（per artifacts/scripts/conftest.py）；wrapper 跑列回傳 result object 含 `returncode` 與 `combined_output` 屬性；stderr/stdout 字面斷言可走 `assert "expected_literal" in result.combined_output` pattern。
- F-5: PR-032 anchor 採 multi-assertion 模式（per PR-021 之 4 assertions 先例 in artifacts/scripts/drills/prompt_regression_cases.json:530-571），可對三 wrapper 各設 file path + must_contain_all；review wrapper 之 must_contain_all 採差異化字面（100000 / 200000）對齊其 diff-driven 寬鬆 bounds。
- F-6: Review wrapper 之 typical $promptSize 為 10k-100k chars（含 diff text + 固定模板 ~700 char；TASK-1052 之 64k diff 為實測上限 per memory/feedback_codex_model_tier_v2.md）；故 review wrapper 之 warn threshold 100k / reject 200k 為 generous 設計，不破既有 use case；dispatch wrapper 採 TASK-1064 之 500/5000 hybrid threshold 對齊 docs/dispatch_prompt_discipline.md。
- F-7: 既有 wrapper param 區段之最尾條目（Invoke-CodexAgent.ps1:50 之 `$IncludeLifecycleInBaseline` / Invoke-GeminiAgent.ps1:40 之同 / Invoke-CodexReview.ps1:64 之 `$ShowHelp`）為適合插入 `-SuppressSizeWarn` 之相鄰位置；新 switch param default = $false（即 default enforce bounds-check）。
- F-8: TASK-1064 之 docs/dispatch_prompt_discipline.md 已立 500-char threshold；本 task 之 dispatch wrapper bounds 與其一致；review wrapper 之 100k 上界屬「Audit Procedure」段之擴充（diff-driven prompt 之 governance 補充），plan §CP-X 須補 docs 一行 cross-reference 完善 reference 鏈。
