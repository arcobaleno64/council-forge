## Objective

強化 `artifacts/scripts/run_red_team_suite.py` 的 subprocess execution 邊界：
1. 所有 subprocess 呼叫加入 timeout（wall-clock 上限）
2. Timeout 產生明確 TIMEOUT / FAIL 結果，不得誤判為 pass
3. Hung process 必須可被終止，不得造成 suite 卡死
4. stdout / stderr capture 有大小上限，防止無限輸出造成記憶體膨脹或卡死
5. subprocess exit code 必須被保留並記錄
6. timeout / exception / non-zero exit 三者明確區分

## Background

`run_red_team_suite.py` 使用 `subprocess.run(..., capture_output=True)` 執行 guard validators 與 git fixture 操作，但無 timeout 保護。若被測 subprocess 掛住（例如等候 credential、無限 loop、deadlock），整個 red-team suite 將永遠卡死，無法產生 FAIL 結果。

v3.4 plan §4.6c 要求建立 timeout + subprocess hardening，作為 Prompt 6e full red-team execution 的安全前提。
