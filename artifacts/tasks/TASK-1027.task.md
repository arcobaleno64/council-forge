## Constraints

- **policy-only**：本任務只交付 lifecycle 五件 + matrix policy JSON 一件（共 6 件 staged）。**不**新建 runtime code、**不**新建 template mirror、**不**新建 evidence file（policy 自身已是評估對象，無需 self-check runner）。
- **presence-only**：matrix 之 `presence_only` 必為 `true`；**不**評估 artifact 內容品質、語意、schema 合規。
- **不生成內容**：matrix MAY 要求 SRS / RTM / design spec / threat model / release note / migration note / user guide / runbook 之 PRESENCE，但**不**生成其 CONTENT。
- **不對已完成任務 retroactive 重評**：supersession_policy.completed_tasks_retroactive_evaluation = `false`；legacy_task_policy.pre_matrix_tasks_retroactive_evaluation = `false`。
- **superseded task 凍結**：superseded_task_obligation_state = `frozen`；superseding task 繼承未結 obligation（除非 decision artifact 顯式 waive）。
- **waiver 機制**：沿用 decision artifact `## Guard Exception` 結構；**不**建 standalone waiver registry；**不**建 style debt registry；六欄齊備（rule_id / scope / reason_code / owner / evidence_ref / expires_at）；narrative-only 不算；過期 waiver 無效。
- **不修改** TASK-1023 / TASK-1024 / TASK-1025 / TASK-1026 任一 artifact（讀取作為 dependency input 允許）。
- **不修改** v3.4 chain artifact、source/template paired files、Bootstrap Skill artifact、`.obsidian/core-plugins.json`、`.omc/`、`.pytest-basetemp/`、`.tmp/`。
- **不執行** ruff、mypy、pyright、coverage、pylint、bandit、safety、pytest、formatters、package managers。
- **不創建** `__pycache__` / `.pytest_cache` 新 entry；本任務不執行 Python script。
- **不創建** waiver registry / style debt registry / policy registry。
- **不宣告** FIND-18 為 Mitigated。
- **不執行** validator module split（FIND-30，屬 v3.5.1 / v3.6）。
- **不抽** policy registry。
- **不擴張** rule_axes 之 assurance_level 加入 `high`（assurance_level 嚴限 {poc, mvp, production}，與 docs/artifact_schema.md §5.11.1 一致）。
- **不引入** `architecture_critic` / 額外 reviewer 角色（per-task agent_roles 限本任務聲明者）。
