## Background

v3.5.0 治理品質控制面已封閉（TASK-1023..1027 done），v3.5.1 主題為 Gate Proving and Refactor Readiness（TASK-1028 commit `c46a6f7`）。v3.5.1 之 controls green 嚴格定義要求**正向 self-check pass + 負向 controlled negative test pass + characterization green** 三者齊備，方可進 v3.6 split。本任務承擔 QC-SYNC-001 之**負向證據**。

QC-SYNC-001（[run_quality_gates.py](../../artifacts/scripts/run_quality_gates.py) `run_qc_sync_001`）採兩階段邏輯：

- **Pass 1**：iterate `baseline.source_template_pairs`；計算 current source/template SHA；判定 in_sync / drift / missing；若 baseline 已宣告為 drift/missing 且 current SHA 與 baseline 相同，pass with `baseline_existing`。
- **Pass 2**：discover current pairs in `SOURCE_TEMPLATE_ROOTS`（hardcoded `[("artifacts/scripts", "template/artifacts/scripts")]`）；for each pair 不在 baseline，若 current_status != in_sync 且無 valid waiver，fail with `post_baseline_new_pair_missing_template / missing_source / drift / waiver_invalid`。

waiver 之六欄齊備（rule_id / scope / reason_code / owner / evidence_ref / expires_at）+ 未過期方可降級為 `skipped_with_reason_code`。過期 waiver = blocking。

本任務以六個受控 fixture 證明上述邏輯各路徑：

| Case ID | Scenario | Expected status | Expected reason_code |
|---|---|---|---|
| QC-SYNC-NEG-001 | post-baseline source-only addition | fail | post_baseline_new_pair_missing_template |
| QC-SYNC-NEG-002 | post-baseline template-only addition | fail | post_baseline_new_pair_missing_source |
| QC-SYNC-NEG-003 | post-baseline source/template drift | fail | post_baseline_new_pair_drift |
| QC-SYNC-NEG-004 | valid unexpired waiver covers drift | skipped_with_reason_code | post_baseline_new_pair_waivered_until:2099-12-31 |
| QC-SYNC-NEG-005 | expired waiver does not cover drift | fail | post_baseline_new_pair_waiver_invalid:expired:2020-01-01 |
| QC-SYNC-NEG-006 | baseline-existing unchanged drift | pass | baseline_existing |
