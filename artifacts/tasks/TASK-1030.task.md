## Background

v3.5.0 治理品質控制面已封閉（TASK-1023..1027 done），v3.5.1 主題為 Gate Proving and Refactor Readiness（TASK-1028 commit `c46a6f7`）。TASK-1029 已補上 QC-SYNC-001 之負向證據（commit `c75c3fe`）。本任務承擔 PCACC v3.5.0 之**負向證據**，與 TASK-1029 為 v3.5.1 manifest `execution_order` 之並行 fork（兩者皆 `depends_on=[TASK-1028]`）。

PCACC v3.5.0（[run_precommit_check.py](../../artifacts/scripts/run_precommit_check.py)）為**結構性檢查**（structural only），非 reasoning-faithfulness audit、非 belief-state audit、非 model self-confidence audit。四項 active checks：

- **PCACC-001 lifecycle artifact set exists**：task / plan / decision / verify / status 五件齊備。
- **PCACC-002 Evidence Refs exist and match required format**：verify artifact 之 `## Evidence Refs` 區段非空且 paths 可解析。
- **PCACC-003 status owner / reviewer references are canonical**：status.current_owner ∈ canonical_owners（Claude / Codex / Gemini）；task.Owner ∈ canonical_owners；final_approver.reviewer_id ∈ canonical_reviewers（arcobaleno）。
- **PCACC-004 review_timestamp > evidence_generated_at**：strict comparison；missing timestamps 必為 `skipped_with_reason_code` 並帶 explicit reason_code（never silent pass）。

policy 之 `output_policy.free_text_rationale = false` 為強制不變條件；`checks` 必為四項（PCACC-001..004）；任何擴張嘗試（如加 PCACC-005 AC-to-verify coverage）由 `validate_policy()` 拒絕。

本任務以八個受控案證明上述邏輯各路徑：

| Case ID | Scenario | Target | Expected status | Expected reason_code |
|---|---|---|---|---|
| PCACC-NEG-001 | missing lifecycle artifact (status.json absent) | PCACC-001 | fail | lifecycle_missing:status |
| PCACC-NEG-002 | malformed Evidence Ref | PCACC-002 | fail | malformed_refs |
| PCACC-NEG-003 | missing Evidence Ref when required (empty section) | PCACC-002 | fail | evidence_refs_section_empty |
| PCACC-NEG-004 | non-canonical owner/reviewer reference | PCACC-003 | fail | non_canonical |
| PCACC-NEG-005 | review_timestamp earlier than evidence_generated_at | PCACC-004 | fail | review_before_evidence |
| PCACC-NEG-006 | missing timestamps must yield explicit reason_code (no silent pass) | PCACC-004 | skipped_with_reason_code | no_review_or_evidence_timestamp |
| PCACC-NEG-007 | forbidden free_text_rationale field activation | policy.output_policy | fail | output_policy_free_text_rationale_must_be_false |
| PCACC-NEG-008 | attempted AC-to-verify coverage activation as 5th active check | policy.checks_count | fail | checks_count_must_be_exactly_4_got_5 |

PCACC-NEG-006 之 `expected_status=skipped_with_reason_code` 對應 v3.5.0 policy 顯式條款「Missing review_timestamp or evidence_generated_at returns skipped_with_reason_code, never silent pass」；此為 prompt §8.6 之 "or equivalent" 條款下「fail-without-silent-pass」之等價操作行為。
