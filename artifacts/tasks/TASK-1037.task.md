## Description

TASK-1037 implements the golden CLI coverage planned in TASK-1036
(`artifacts/governance/golden-cli-coverage-matrix.v3.5.4.json` +
`artifacts/governance/golden-cli-coverage-expansion-plan.v3.5.4.md`).

A standard-library-only test harness lives under
`artifacts/verify/TASK-1037/run_golden_cli_coverage.py`. Controlled fixtures
live under `artifacts/verify/TASK-1037/fixtures/`. The harness invokes the
production PCACC runner (`artifacts/scripts/run_precommit_check.py`) and the
production quality gate runner (`artifacts/scripts/run_quality_gates.py`)
through subprocess against fixture-local repo roots and fixture-local
policies / baselines / registries. Production runner bytes are not modified;
fixture-local runner copies are byte-identical to the production runners.

The harness asserts robust output contracts (exit code, stdout JSON field
subset, stderr empty, post-run no `__pycache__`), not full-output byte
equality. A machine-readable result lives at
`artifacts/verify/TASK-1037/golden-cli-coverage-result.json`.
