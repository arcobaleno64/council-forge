## Description

TASK-1038 records a closure snapshot of the v3.5.x governance work
already committed. It produces a human-readable narrative under
`artifacts/governance/v3.5.x-governance-closure-snapshot.md` and a
machine-readable index under
`artifacts/governance/v3.5.x-governance-closure-index.json`. The
snapshot summarizes verified TASK-1023..TASK-1037 lifecycles
(including the TASK-1037 status-semantics repair) and identifies
non-authorization boundaries that must remain in place for any
future v3.5.6+ or v3.6 work.

Snapshot inspection evidence lives at
`artifacts/verify/TASK-1038/closure-snapshot-inspection.json` with
schema `closure-snapshot-inspection/v1`. An optional standard-library
static inspection helper may live at
`artifacts/verify/TASK-1038/inspect_closure_snapshot.py`.

TASK-1038 is index/snapshot work only. It does not modify production
runners, production validator/test files, governance policies, the
v3.5 / v3.5.1 plan or manifest, or any prior task lifecycle artifact.
It does not extract a new registry, implement new tests, split
validators, or activate any new active check. It does not create
TASK-1039+ lifecycle artifacts.
