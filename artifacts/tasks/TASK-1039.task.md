## Description

TASK-1039 creates a design-only waiver policy registry prototype.
The prototype consolidates waiver semantics already observed across
committed governance artifacts (`quality-gate-policy.v3.5.json`
waiver_policy schema, `artifact-obligation-matrix.v3.5.json`
waiver_policy mechanism, `evidence-ref-policy.v3.5.3.json` RRC-5
waiver evidence_ref context, and the
`golden-cli-coverage-matrix.v3.5.4.json` GCLI-QUALITY-SYNC waiver
case shapes) into a single readable contract source for any future
runtime extraction.

TASK-1039 is design-only. It does not implement runtime
consumption. It does not modify production runners
(`run_precommit_check.py`, `run_quality_gates.py`) or their template
mirrors. It does not modify production validator/test files
(`guard_status_validator.py`, `guard_contract_validator.py`,
`workflow_constants.py`, `run_red_team_suite.py`,
`test_guard_units.py`). It does not modify production governance
policies. It does not modify TASK-1023..TASK-1038 lifecycle
artifacts. It does not create TASK-1040+ lifecycle artifacts.

The prototype JSON resides at
`artifacts/governance/prototypes/waiver-policy-registry.prototype.v3.5.7.json`,
deliberately under `prototypes/` (not under `artifacts/governance/`)
to keep it out of any current runner load path. The companion
design note resides at
`artifacts/governance/waiver-policy-registry-prototype-design.v3.5.7.md`.
Inspection evidence resides under
`artifacts/verify/TASK-1039/waiver-policy-prototype-inspection.json`
with optional standard-library inspection helper at
`artifacts/verify/TASK-1039/inspect_waiver_policy_prototype.py`.
