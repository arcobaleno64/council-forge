## Description

TASK-1040 creates a planning-only runtime extraction plan for the
waiver policy registry prototype delivered by TASK-1039. The plan
defines the safe future path to runtime consumption (activation
model, runtime loading model, fail-closed matrix, waiver selection
and matching semantics, Evidence Ref integration, golden CLI
coverage requirements, runner/template mirror preservation,
backward compatibility, rollback strategy, and future TASK-1041
acceptance criteria) without implementing any of it.

TASK-1040 is planning-only. It does not implement runtime
consumption. It does not modify the waiver prototype registry
(`artifacts/governance/prototypes/waiver-policy-registry.prototype.v3.5.7.json`).
It does not modify production runners (`run_precommit_check.py`,
`run_quality_gates.py`) or their template mirrors. It does not
modify production validator/test files (`guard_status_validator.py`,
`guard_contract_validator.py`, `workflow_constants.py`,
`run_red_team_suite.py`, `test_guard_units.py`). It does not
modify production governance policies. It does not modify
TASK-1023..TASK-1039 lifecycle artifacts. It does not create
TASK-1041+ lifecycle artifacts.

The human-readable runtime extraction plan resides at
`artifacts/governance/waiver-policy-runtime-extraction-plan.v3.5.8.md`.
The machine-readable plan resides at
`artifacts/governance/waiver-policy-runtime-extraction-plan.v3.5.8.json`.
Inspection evidence resides under
`artifacts/verify/TASK-1040/waiver-runtime-extraction-plan-inspection.json`.
