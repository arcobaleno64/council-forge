## Description

TASK-1042 lands the smallest safe runtime surface for waiver
policy consumption inside the quality gate runner only. The task
is implementation-authorized by the human maintainer
(`arcobaleno`) on top of the TASK-1041 readiness decision
(`ready_for_separate_human_authorization`); TASK-1042 itself
does not lift any non_authorization boundary recorded in
TASK-1040 plan JSON or TASK-1041 readiness matrix beyond the
runtime consumption surface explicitly authorized by FTC-1.

TASK-1042 modifies exactly two production files:

- `artifacts/scripts/run_quality_gates.py`
- `template/artifacts/scripts/run_quality_gates.py`

These two files remain byte-identical after TASK-1042. A new
explicit `--waiver-policy <path>` CLI argument is added; default
behavior without the flag is preserved byte-identically against
the TASK-1029 / TASK-1037 fixtures. The flag, when supplied,
loads a `waiver-policy-registry/v1` registry from the explicit
path. Registry load failures fail closed with exit code 2 and a
machine-readable error envelope. Valid active unexpired waivers
suppress only the targeted QC-SYNC-001 finding; non-QC-SYNC-001
surfaces (QC-SCHEMA-001, QC-IMPORT-001, QC-GOLDEN-001, QC-RUFF-001
advisory, PCACC, Evidence Ref registry, validator findings) are
unaffected.

TASK-1042 does NOT modify `run_precommit_check.py`. TASK-1042
does NOT modify any production validator/test file. TASK-1042
does NOT modify any production governance policy. TASK-1042
does NOT modify the TASK-1039 prototype registry / design note,
the TASK-1040 runtime extraction plan markdown / JSON, or the
TASK-1041 readiness decision markdown / matrix JSON / inspection
JSON. TASK-1042 does NOT create a production waiver registry;
the only registries that exist under TASK-1042 are isolated
fixture registries under `artifacts/verify/TASK-1042/fixtures/`
with `registry_status=runtime_test_fixture`. TASK-1042 does NOT
introduce PCACC-005, expand the PCACC active surface, or
activate AC-to-verify coverage. TASK-1042 does NOT execute or
create any TASK-1043+ lifecycle artifact.
