User chose path β (schema/validator evolution) over α (artifact rewrites) and γ (waiver quarantine) because the v2 schema represents a deliberate evolution from the PDCA / double-loop learning chain and should be supported, not undone. Path β must keep production validators green, must keep the source-template sync contract intact, and must not regress any v1-format artifact.
