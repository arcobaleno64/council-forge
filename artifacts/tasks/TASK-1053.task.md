## Objective

修復 dispatch wrappers 之長期 bug，並順手收斂兩 wrapper 之 model fallback 設定，最後以一次真實 Council 試跑解鎖 TASK-1052：

1. **Layer 1**：`Invoke-CodexAgent.ps1` cmd 8191 字限制——當 prompt 長度超過閾值時自動切 stdin pipe 模式（`$Prompt | & codex.cmd exec ...`），避開 Windows cmd.exe 之 args 總長度上限。
2. **Layer 2**：`Invoke-CodexAgent.ps1` 與 `Invoke-GeminiAgent.ps1` 失敗路徑保留 stderr——retry / escalation 之前 dump `$combinedText` 末 30 行至 console，user 可看見真正錯誤訊息。
3. **Layer 3**：`Invoke-CodexAgent.ps1` 之 deprecated `--full-auto` 替換為 `--sandbox workspace-write -a never`（codex 0.128 仍 deprecation warning，未來版本恐拒）。
4. **Layer 4**：`Invoke-CodexAgent.ps1` 之 `Get-TaskScaleProfile` 對齊新版 tier ladder v2——低 mini / 中 5.4 / 高 5.5；effort 一律 `high`；移除 `gpt-5.3-codex` / `xhigh`；`-TaskScale` 之 ValidateSet 8 舊值保 backward-compat 之 mapping，caller 不需改介面。
5. **Layer 5**：`Invoke-GeminiAgent.ps1` 之 `$Models` 移除 `gemini-3.1-pro-preview`（user 帳號未開通；每次浪費 2 retry）；fallback 收斂為廣度 `gemini-3.1-flash-lite-preview` + 深度 `gemini-3-flash-preview` 兩階。

最終以一次真實 `Invoke-CodexReview.ps1 -DiffSource HEAD` 試跑（消耗中等 tokens）e2e 驗證 cmd 8191 修復 + stdin pipe + sandbox flag + tier ladder 四 layer 同時 work，並解鎖 TASK-1052 之首次真實 Council。
