## Objective

建構 sub-agent write scope guard，分兩層：

- **Layer A（強制層）**：`Invoke-CodexAgent.ps1` 與 `Invoke-GeminiAgent.ps1` 新增 `-AllowedPaths` 與 `-AutoRestore` 參數；dispatch 完成後（成功或失敗）做 post-dispatch git status 檢查；超出 AllowedPaths 之 file write 報 [GUARD] 違規 + exit 2；若 `-AutoRestore` 設定，自動 git restore tracked 檔 + 刪 untracked 檔。
