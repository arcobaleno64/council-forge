## Objective

修復 TASK-1057 wrapper 之 `-AutoRestore` baseline 計算缺陷（per `artifacts/decisions/TASK-1057.decision.md` §Chosen Option B）。將兩 wrapper（`Invoke-CodexAgent.ps1` / `Invoke-GeminiAgent.ps1`）之 dispatch flow 改為 stash-based pre-dispatch snapshot：

1. **Pre-dispatch snapshot**：dispatch 開始前以 `git stash push -u -m "TASK-1057 pre-dispatch <timestamp>"`（`-u` 含 untracked）保存 user 既有 working tree state；紀錄 stash ref 至 wrapper 內部變數。
2. **Dispatch on clean tree**：sub-agent 在 clean working tree 上操作；wrapper post-dispatch 之 `git diff HEAD --stat` 即可純粹反映 sub-agent 之寫入 delta。
3. **Targeted enforcement**：`-AllowedPaths` 比對僅針對 sub-agent 之 delta；違規時 `git checkout HEAD --` + `git clean -fd` **僅** 對違規 paths（非全 repo）。
4. **Pop user state**：dispatch 結束（成功 / 失敗 / 違規處理後），`git stash pop` 恢復 user pre-dispatch state；合法之 sub-agent 寫入仍保留於 working tree（以 stash apply / drop 之 git 機制達成）。
5. **Conflict fallback**：stash pop 若於 sub-agent 寫入路徑與 user pre-dispatch state 衝突時，wrapper exit 3 + 印 `[FATAL] stash pop conflict; user state preserved in stash@{N}; manual resolution required`，user 須手動 `git stash list` + `git stash apply` 解。

並追加保守降級層：
- 兩 wrapper 之 `-AutoRestore` 預設值改為 `$false`（既有 caller 不再自動觸發 restore）；新增 `-AutoRestoreLegacy` 為過渡 flag（標 `[DEPRECATED]` 並印 warning）以 backward-compat 既有 dispatch script。
- 新增 `prompt_regression_cases.json` PR-029（wrapper safety regression）+ `test_guard_units.py` 之 mock smoke 確保 user pre-existing M 檔未被 wrapper 接觸。
