## Objective

修復兩 dispatch wrapper（`Invoke-CodexAgent.ps1` / `Invoke-GeminiAgent.ps1`）之 `Save-PreDispatchState` 缺陷：當 caller 設 `-AllowedPaths` 而 task lifecycle artifacts（`artifacts/{tasks,research,plans,code,test,verify,status}/` 之 7 dir）尚未 commit 時，wrapper 之 `git stash push -u` 會將其一併隱藏，致 sub-agent 在乾淨樹上看不到 plan / research / task 等 prerequisites 而自我 block（per CODEX.md / GEMINI.md 「plan 缺失即 STOP」之契約）。

修復方針（per user routing 2026-05-07）：

1. **Default exclude**：`Save-PreDispatchState` 在 stash 時，default 排除 7 lifecycle dirs 之全部檔（含 tracked-modified、untracked、staged）；sub-agent 永遠看得見 lifecycle artifacts。
2. **Opt-in include via `-IncludeLifecycleInBaseline`**：新增 switch param，caller 顯式設此 flag 時恢復「全 stash」之舊行為（用於 wrapper-self-test 等需 strict 模式之 case）。
3. **Hard-code 7 dirs**：exclude pattern 為 `artifacts/tasks/`, `artifacts/research/`, `artifacts/plans/`, `artifacts/code/`, `artifacts/test/`, `artifacts/verify/`, `artifacts/status/`，不引入 `-TaskId` param、不接受任意 `-ExtraExcludePaths`（屬 Out of Scope）。
4. **Pytest 覆蓋**：複用 TASK-1054 之 `conftest.py` fixture（`fake_codex_exe` / `fake_gemini_exe` / `tmp_repo` / `run_wrapper`）新增 wrapper-level test case，覆蓋 default-exclude 與 opt-in include 兩 path。
5. **PR-029 assertion 同步**：`prompt_regression_cases.json` 之 PR-029 之 `must_contain_all` 補 `IncludeLifecycleInBaseline` 字面值，pin 介面契約。
6. **Doc 同步**：`CODEX.md` / `GEMINI.md` 之 §Write Scope Discipline 段補一句說明 lifecycle exclusion default 行為與 opt-in flag；root + template/ 鏡像 SHA-256 一致。
