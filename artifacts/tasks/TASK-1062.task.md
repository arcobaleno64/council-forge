## Objective

修復 `Invoke-CodexAgent.ps1` 與 `Invoke-GeminiAgent.ps1` 之 post-dispatch write-scope guard：當 caller 傳 `-AllowedPaths` 且 lifecycle 內未 commit 之 prerequisite artifacts（task / research / plan / status）存在時，guard 應將其視為「user pre-existing untracked」而非「sub-agent writes」，避免被 `Restore-PostDispatchDelta` 誤刪。

TASK-1060 之 lifecycle exclusion 只解 stash 階段之 visibility（讓 sub-agent 看得見 prereq）；未解 post-dispatch 階段之 classification（git status 仍視為 untracked，被 guard 當成 sub-agent write）。

1. `Save-PreDispatchState` 因 `-IncludeLifecycleInBaseline=$false`（default）排除 7 lifecycle dirs，未 stash 兩檔 → sub-agent 可見 ✓
2. Gemini 完整寫入 research artifact ✓
3. Post-dispatch guard 跑 `git status --porcelain --untracked-files=all`，仍見兩檔為 untracked → 視為 sub-agent writes outside AllowedPaths
4. `Restore-PostDispatchDelta` 對 untracked 走 `Remove-Item -Recurse` → 兩檔被刪 ✗
