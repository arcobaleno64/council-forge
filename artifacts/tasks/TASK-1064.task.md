**設計準則（來自 feedback memory）**：
- **< 500 字 instruction / anti-fabrication rule / scope constraint**：inline OK（語意密度高；fabrication 防護必 inline）
- **> 500 字 artifact / spec / 規則章程**：dispatch prompt 只給 path，令 sub-agent Read

- **Sub-agent fabrication 風險高之引用**（如 SHA / 版本號 / 行號）：永遠 inline 並標 UNVERIFIED 或要求 sub-agent 直驗

**HEAD anchor**：`8938d9e`（TASK-1063 council-review revert + TASK-1062 reopen pass 收束後）。pytest baseline = 1310。三 wrapper 字面為當前 stable 版本（TASK-1062 commit `b5b7e32` 落 Bug A + Bug B fix）。
