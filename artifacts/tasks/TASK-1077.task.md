## Objective

P8-A（SSDLC 形式化之基石）：將 council-forge 對 **NIST SSDF SP 800-218 v1.1**（PO/PS/PW/RV，19 practices）之覆蓋，由 prose 化為 **machine-checked mapping integrity**。二產出：
1. `docs/ssdf-mapping.md`——每 SSDF practice 之正式映射列（practice id / title / status / mechanism ref / evidence / gap-or-waiver）。
2. `ssdf_mapping_validator.py`（source-only，read-only）——校 mapping 之**完整性與誠實性**（**非「認證 conformance」**）。

### 校驗契約（含三輪 codex+gemini 對抗審查之全部 blocking 修正）

**(A) canonical 完整性**：19 canonical practices（PO.1-5、PS.1-3、PW.1/2/4/5/6/7/8/9、RV.1-3；**PW.3 於 v1.1 已移除**）全列，無缺/冗/未知。

**(B) status 合法**：∈ {covered, partial, gap}。

**(C) 統一 repo-bound ref resolver**（杜偽 ref）——`covered`/`partial` 列之 **Mechanism 與 Evidence 二欄皆須以同一 resolver 真能 resolve**（非僅 Evidence、非僅非空）：
- ref 為 repo-relative path（`path`、`path#anchor`、`path:line`）；
- 檔須**存在**於 repo root 下；
- 若 `#anchor`：**僅**匹配檔內 markdown **標題之 slug**，以**明定之 `slugify()`**（小寫 ASCII、Unicode/CJK 原樣、剝 ASCII 標點、空白→連字號、連字號收斂、重複標題加 `-1`/`-2` 後綴；確切算法落 docstring，不託模糊「GitHub 式」）；**不接受寬鬆字面/子字串比對**（免誤匹配 body 文本致假 resolve）；
- 若 `:line`：須**正整數且在檔行數內**；
- **拒絕** absolute 路徑與 `..` traversal（path safety）；
- **禁 `cmd:` 及任何非-path**（opaque 命令不可 durable 驗，且與 no-subprocess import guard 一致）。

**(D) waiver resolver（全對稱結構化 marker：二形式皆須明示宣告 `SSDF-Gap-Waiver: <practice_id>`，棄非結構化 mention 啟發式）**——`gap` 列之 Gap/Waiver 須 resolve 至：
- `docs/ssdf-roadmap.md#<anchor>`（**canonical repo-relative 路徑**；檔存在 + anchor 為真標題 slug + **該 anchor section 內含 `SSDF-Gap-Waiver: <practice_id>` marker**，section-scoped 自標題至下一同級/更高級標題），或
- `decision:TASK-NNNN`（`artifacts/decisions/TASK-NNNN.decision.md` 存在 + 含 `SSDF-Gap-Waiver: <practice_id>` marker）。
- 二者無 marker / practice_id 不符 / draft 無關 → unresolved。P8-A 於 roadmap 各 owns-gap 階 section 補該 marker（roadmap 成 waiver registry）。

違 (A)-(D) 任一 → **完整性違規（exit 2）**。

### 誠實 exit 語意（杜「虛假 SSDLC 認證」訊號）

此工具校 **mapping 完整性**，**非 SSDLC 認證**：
- `exit 0` = 結構有效**且全 19 列皆 covered**（零 partial、零 gap = 真全覆蓋）；
- `exit 3` = 結構有效**但有 open items**（>=1 partial 或 >=1 gap；valid-with-open-items；council-forge 現態，含 partial 與 4 gap）；
- `exit 2` = 完整性違規（缺列/非法 status/mechanism|evidence|waiver 不能 resolve）；
- `exit 1` = usage/IO。
- 輸出（markdown+json）**恆報** covered 計數 + **partial IDs 與 gap IDs（兩列）**；exit-3 文案明曰「open items」；**絕不**輸出裸「conformant」，亦不曰「full coverage」當有 open items。

mapping 之 gap 欄即自然產出 P8-B/C/D backlog；**缺口不得無聲復長**（drift_dashboard 之理施於標準 conformance）。

## Constraints

- **映射而非再造**：validator **引用**既有機制，不重寫安全邏輯，**不執行任何安全掃描**。

- **programmatic scope-creep guardrail**：測斷言 `ssdf_mapping_validator.py` **不 import** `subprocess`／`os.system`／安全掃描模組——技術屏障阻其日後擴為真掃描。

- **避免疊床架屋**：mapping 為單一事實源（validator 直解 markdown 表，不另立平行 JSON）。
- **本階不含實控**：P8-A 僅建 mapping + integrity gate；SAST/SCA/SBOM/secret-scan/release 模板為 P8-B/C/D（gap 欄記 backlog）。
