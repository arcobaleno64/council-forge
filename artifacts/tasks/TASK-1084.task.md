## Constraints

- **零 theater（樞）**：不生 demo/throwaway 之**持久** key、**不 commit 任何 private key**、**不 flip PS.2 covered**（無真簽章+out-of-band trust anchor 前）；不以 self-referential（pubkey+sig+file 同 repo 無獨立 anchor）即稱 covered；ephemeral-key 唯測時生·用·棄（不持久、不稱 identity）。
- **守 no-push**：本地 branch commit only；pubkey/fingerprint 之 out-of-band 刊布（push）為 operator 後續，非本 task。
- **誠實上限 partial**：PS.2 維 `partial`+ mechanism-implemented footnote；validator 仍 exit 3、不偽升。
- **map-don't-recreate / 不重造 crypto**：真簽章驗交 native `gpg --verify`（subprocess step）；**release_gate 不動**（stdlib·無 crypto·無 subprocess）；**簽章 detached，manifest schema 不動**。
- **fingerprint-pin 之誠實**：CI 比對 pinned fingerprint，然**明標同-repo pin 僅及 repo 完整性**；真 publisher trust 須 out-of-band（operator）。
- **gate 家族紀律**：base snapshot_manifest/release_gate step 維 sentinel-only·恆跑（不因簽章條件而 skip）；native-verify 為獨立 conditional step（subprocess 居 step 非 gate）。無 masking。
