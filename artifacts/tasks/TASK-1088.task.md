## Objective

FB-1（承 TASK-1087 CP-4 立即重審揪出之最急質之 delta）：`artifacts/scripts/repo_security_scan.py` 之掃描讀取路徑 **fail-OPEN**——`read_text()` 將 `OSError`（不可讀）/ oversize / NUL-binary 三態俱歸 `None`，`scan_secrets`/`scan_static`/`scan_sast` 皆 `if text is None: continue` 靜默跳過，`main` 復 `return 1 if findings else 0`，故一個 in-scope 之 text 候選檔若**讀取失敗**而被靜默丟出覆蓋範圍、且他處無 finding，即 exit 0（偽「乾淨通過」）。另 `main` 未驗 `--root` 存在，**nonexistent root → exit 0**（codex 親跑覆現）。

依 **TASK-1079 fail-closed 紀律**（「scan/parse 錯誤或缺報告＝hard fail，永不靜默 pass」），改為：**genuine 讀取失敗（OSError）= fail-closed hard error**；**nonexistent/非目錄 root = fail-closed**。oversize / NUL-binary 為 `read_text` 既定之**非文本 scope 限**（`MAX_FILE_BYTES` DoS 守 + binary 守），維 deliberate skip（非 coverage 失敗），但須界明。
