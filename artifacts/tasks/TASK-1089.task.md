## Objective

FB-2（承 TASK-1087 CP-4 立即重審揪 TASK-963 之質之 delta）：`artifacts/scripts/publish-release.ps1` 之 preflight 於 `gh release create` 前**無 release-integrity / release-signing 驗證**即發布——與 P8-D2（release_gate / snapshot_manifest）/ P8-D3（gpg detached-signature 簽章驗證）之 bar 不符（可發布未驗、未簽之 release）。

修：preflight 於 `gh release create` **前**耦合二驗證 **fail-closed**（不過則中止、不發布）：
1. **結構 integrity gate**——`release_gate.py --file .well-known/release-manifest.json --format checksums`（offline 結構驗：schema/algo/digest/min-entries，fail-closed）。
2. **gpg 簽章驗證（鏡 CI security-scan.yml release-integrity job 之已證範式）**——**signing triad**（pinned `EXPECTED_SIGNING_FINGERPRINT` ＋ detached `.well-known/release-manifest.json.asc` ＋ public `.well-known/release-signing.pub`）**armed-vs-unprovisioned**：零 present → 未 provisioned → skip 簽章驗（結構 gate 仍守）；任一 present → **ARMED → 三者俱全 + `gpg --verify` 之 VALIDSIG 精確 fingerprint 綁定否則 FAIL CLOSED**（capture-then-check、exact-field-equality、40-hex pin 驗）。

## Constraints

- **fail-closed（樞）**：integrity gate 失敗 → 中止；簽章 ARMED 而驗證失敗 → 中止；永不發布未驗 release。
- **不誤殺 bootstrap**：簽章未 provisioned（triad 零 present）→ skip 簽章驗（結構 gate 仍守）——合 release-signing.md「PS.2 partial、簽章為 operator action」之誠實殘留；不強制阻所有發布。
- **鏡 CI 已證範式**：簽章驗證邏輯鏡 security-scan.yml release-integrity job（triad armed-vs-unprovisioned、capture-then-check、VALIDSIG exact-field-equality、40-hex pin 驗）——map-don't-recreate，不另造 crypto。
- **byte-identity**：publish-release.ps1 + github_publish_common.ps1 root↔template byte-identical；改 template → release-manifest 重生（若 template/ 該檔入 manifest）。release_gate.py 不改。
- **surgical**：唯加 preflight 驗證步驟（+ 必要 helper 於 github_publish_common.ps1）；不改 release 建立邏輯/CLI 既有 param（可加 `-AllowUnsigned` 明示 override）。
- **雙審 gate**：plan 過 codex+gemini 雙審；security 碼動工後加 working-tree 實作層雙審。
