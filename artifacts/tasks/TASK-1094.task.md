## Objective

修 release-integrity manifest 之**跨平台不可復現缺陷**：`.well-known/release-manifest.json`（PS.2.1 acquirer 完整性憑據）於本機 Windows（CRLF working tree）生成、所記 digest 係 CRLF bytes；Linux CI（LF checkout）以 `snapshot_manifest verify` 重算得 LF digest → 眾文字檔 digest 全異 ＋ root mismatch → **`release-integrity` job 與 `validate` 之 2 測（`test_council_forge_release_manifest_matches_template_snapshot`、`test_integrity_gate_passes_on_valid_repo`）於 CI 紅**（PR #14 實證）。此使 snapshot_manifest 自誓之「byte-reproducibility is the whole point — a hash nobody can reproduce is theater」**名實不符**（其只正規化路徑為 POSIX、未正規化行尾）。

修法（正本清源，雙審 round-1 裁 A+B 妥並硬化）：令 manifest 之 content-address **對文字檔整檔讀入、正規化行尾（CRLF/CR→LF）後雜湊**（**整檔讀**杜 chunk-boundary `\r\n` 誤拆，gemini），使 manifest 與 working-tree 行尾組態無關；**強判別 fail-closed**——text ⇔ UTF-8 可 decode 且無 NUL，否則 binary（原始 bytes、不正規化，codex）；**canonicalization acquirer-可見**——manifest 加 `digest_canonicalization:"text-eol-lf-v1"`（schema `@2`）、verify 缺/誤即 fail-closed、三 acquirer 文載復現規約（codex）；輔以 `.gitattributes` 釘 LF（衛生）；重生 manifest；補測鎖此不變量。今 repo 無追蹤二進位（text-only 不變量），強判別為未來 fail-closed 防。

## Background

PR #14（branch `hygiene/task-1070-contract-guard-green` → master）CI 八閘六綠、二紅，皆源 release-manifest digest 不符。recon 實證（2026-06-12，HEAD `a1a31a1`）：
- `git config core.autocrlf` = **true**；repo **無 `.gitattributes`**。
- `git ls-files --eol`：文字檔 **i/lf**（git object 皆 LF，autocrlf commit 時正規化）、**w/crlf**（Windows working tree smudge 為 CRLF）。`git cat-file blob :template/docs/workflow_state_machine.md` = LF-only；working tree = HAS-CRLF。
- `snapshot_manifest.py::sha256_file`（`artifacts/scripts/snapshot_manifest.py`）`open(path,"rb")` 讀**原始 bytes**、無行尾正規化；`compute_manifest` rglob `template/` working tree、逐檔 sha256、sorted、Merkle-ish root。
- 本機 Windows `snapshot_manifest verify` → `[OK] manifest matches (230 entries)` exit 0（CRLF working tree 與 CRLF manifest 自洽）；Linux CI（LF）→ root mismatch。
- 唯一 manifest 檔＝`.well-known/release-manifest.json`（root digest 為其內欄位，非另檔）。
- 追蹤檔**無二進位**（`git ls-files` 無 png/jpg/ico/woff/zip/… ；無 `w/-text`）。

**機制歸屬**：`snapshot_manifest.py` 為 **source-only**（不入 `template/`、不入 EXACT_SYNC，同 scaffold/drift/propagate）——digest 正規化主修於此。`release_gate.py`（family source+template+EXACT_SYNC）為**結構**驗證、**不重算 digest**，然因 manifest 加 `digest_canonicalization` 欄（schema `@2`）須**結構層加容/核此欄**（一行，不重算 bytes），其 template EXACT_SYNC 對偶同步（round-1 codex R9）。`.well-known/release-manifest.json` 為 council-forge 自身發布面（source-only）。

**HEAD anchor**：council-forge `a1a31a1`（branch `hygiene/task-1070...`，已 push、PR #14 open）。**Adapter**：generic。

## Constraints

- **不弱化完整性語義之安全本旨**：正規化僅對**文字檔行尾**（CRLF/CR→LF）——文字治理 SSOT 之行尾無語義/安全 payload，且 content-address 之旨在跨平台 acquirer 可復現（原始-byte 雜湊正違此旨）；二進位（**UTF-8-fail 或含 NUL** 判，強於 NUL-only）雜湊**原始 bytes**不動。**canonicalization 須現於 published 驗證面**（manifest `digest_canonicalization` 欄＋verify fail-closed＋acquirer 文），非僅 docstring——杜 acquirer 依舊「raw sha256」誤算（codex R9）。
- **單一雜湊函式**：generate 與 verify 共用同一（正規化）雜湊路徑（`compute_manifest` 二者共用），杜「generate 正規化、verify 未」致恆不符。
- **重生 manifest 須於碼改之後**：先改 `sha256_file`/雜湊路徑，再 `snapshot_manifest generate` 重生 `.well-known/release-manifest.json`；驗本機（CRLF working tree）與 LF 二者算得**同一 root**（缺一即未達跨平台）。
- **`.gitattributes`（衛生、輔）**：root 加 `* text=auto eol=lf`（repo 無二進位，安全；`text=auto` 仍自動辨二進位免誤改）；`git add --renormalize .` 預期近 no-op（object 已 LF）、僅 `.gitattributes` ＋重生 manifest 入 commit；若 renormalize 產非預期檔變，先究再決。
- **coverage gate**：`snapshot_manifest.py` 現 100% cov（128 stmts）；新增 branch（正規化／強判別／canonicalization）須測涵，否則 `validate` cov gate 紅；`release_gate.py` schema @2 變更亦補 `test_release_gate.py`。
- **scope**：限 council-forge 自身 CI 解阻——root `.gitattributes` ＋ `snapshot_manifest.py`（整檔讀/強判別/正規化/canonicalization 欄）＋ `release_gate.py`（結構核欄，含 EXACT_SYNC 對偶）＋ 三 acquirer 文（`SECURITY.md`／`docs/security/release-signing.md`／`docs/templates/security/README.md`）＋ 重生 manifest ＋測 ＋ docstring。**template/.gitattributes 下傳四下游**（其 `.council-forge/release-snapshot.json` 同有潛在 CRLF 患）列**決策點/follow-up**，不於本 task 擴（避免疊床架屋、避免動四下游 push 面）。
- **release_gate.py 邊界**：**不改**其 digest 重算/crypto 邊界（其本不重算 bytes）；**改**其結構層 schema/`digest_canonicalization` 核（`SUPPORTED_SCHEMA_VERSIONS` 加 @2、@2-only 強制欄），並**同步 template EXACT_SYNC 對偶**。**不動**四下游、Merkle/cruft 排除集（codex r2：原「release_gate 不動」與 R9 相牴，已校）。
- **雙審 gate**：plan 須過 codex + gemini 雙審皆無 blocking/critical 方動工（[[adversarial-review-gate]]，gemini「預設 REJECT、舉證方 APPROVE」）；屬 release-integrity 安全閘碼，動工後加 working-tree 實作層雙審（[[implementation-review-for-security-code]]）。
- **守 no-push 之外**：本 task 修於 PR #14 之 branch `hygiene/task-1070...`（已 push）；commit 後 push 同 branch 令 CI 重跑驗修（PR #14 之 CI 為本修之驗證閘）。master merge 仍候主公（本 task 旨在使 CI 轉綠、解 merge 之阻，非自行 merge）。

## Acceptance Criteria

1. **content-address 跨平台復現**：`snapshot_manifest generate` 於 CRLF working tree 與 LF working tree 算得**同一 manifest（同 root）**；文字檔（**UTF-8 可 decode 且無 NUL**）整檔讀入、行尾正規化（CRLF/CR→LF）後雜湊；二進位（UTF-8-fail 或含 NUL）雜湊原始 bytes、不正規化（fail-closed）。
2. **單一雜湊路徑**：generate 與 verify 共用正規化雜湊；本機 `snapshot_manifest verify` 與 CI（Linux）`verify` 皆 exit 0。
3. **manifest 重生且正確**：`.well-known/release-manifest.json` 經重生，本機（CRLF）與 LF 二環境 verify 皆 `[OK]`、entries 數不減、root 一致。
4. **`.gitattributes`**：root 加 `* text=auto eol=lf`；`git add --renormalize` 後 commit 僅含 `.gitattributes`＋重生 manifest（＋snapshot_manifest 碼/測），無非預期文字檔 churn（object 已 LF）。
5. **測鎖不變量**：補測證 CRLF==LF reproducibility、**chunk-boundary `\r\n`（跨 65536 界）得同 digest**（gemini）、**UTF-8-fail→binary 原始-byte**、**含 NUL→binary**、**canonicalization 欄缺/誤→verify fail-closed**（codex）；`snapshot_manifest.py` cov 維 100%。
6. **canonicalization acquirer-可見**（codex）：published manifest 含 `digest_canonicalization:"text-eol-lf-v1"`（schema `@2`、向後容）；`verify` 對缺/不符 fail-closed；docstring 及三 acquirer 文（`SECURITY.md`／`docs/security/release-signing.md`／`docs/templates/security/README.md`）載復現規約（文字 LF-正規化、二進位原始）；`release_gate.py`（含 template EXACT_SYNC 對偶）結構層容/核此欄。
7. **CI 轉綠**：PR #14 之 `release-integrity` ＋ `validate`（含二 manifest 測）轉 pass；母本三 guard（contract/prompt/guard_status）綠；full gate cov ≥ 90%。
8. **不破他面**：`release_gate.py` 之 digest 重算/crypto 邊界不動（僅加結構 schema/canonicalization 核並同步 EXACT_SYNC 對偶）；四下游、Merkle/cruft 不動；`git diff` 僅本 task 宣告之檔（snapshot_manifest／.gitattributes／manifest／release_gate＋template 對偶／三 acquirer 文／二 test）。
