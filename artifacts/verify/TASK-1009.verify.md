- All 32 files at baseline time → `floor_status = "advisory_until_6d"` (all pre-TASK-1009 historical)

  - path in baseline, sha256 unchanged → `advisory_until_6d`
  - path in baseline, sha256 changed → `strict` (modified after baseline)

New or modified verify artifacts after TASK-1009 are subject to strict enforcement immediately. This is enforced via `--verify-floor-dry-run` targeted check. Full repo enforcement of all historical artifacts is deferred to Prompt 6d / TASK-1015.
