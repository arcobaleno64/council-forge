## Timeout Wrapper / Subprocess Hardening Record

### Hardening Method

| 元件 | 實作 |
|---|---|
| Timeout | `proc.communicate(timeout=SUBPROCESS_DEFAULT_TIMEOUT)` |
| Hung process termination | `proc.kill()` + 再次 `proc.communicate()` |
| Timeout sentinel | `TIMEOUT_RETURNCODE = -9999`（不與 0/1 混淆） |
| Exception sentinel | `EXCEPTION_RETURNCODE = -9998` |
| Output cap | `_cap_output(text, 1 MiB)` byte-level 截斷 + 標記 |
| Git timeout | `run_git_command` 傳入 `timeout=30` |

### Failure Path 區分原則

| 情況 | returncode | passed（expected=0 or 1） |
|---|---|---|
| Subprocess timeout | -9999 | False（FAIL） |
| OS-level exception | -9998 | False（FAIL） |
| Non-zero exit（expected violation） | actual (e.g. 1) | True if expected=1 |
| Normal exit 0 | 0 | True if expected=0 |

### stdout/stderr Capture Policy
