Council Forge 是一套住在 repository 裡的多代理 AI 工作流框架。它不追求「叫模型寫快一點」，而是建立一個有明確邊界、可審查檢查點、持久產物與硬性驗證的交付系統。 Council Forge is a multi-agent AI workflow framework that lives inside the repository itself — built not to make a model code faster, but to create a delivery system with explicit boundaries, reviewable checkpoints, durable artifacts, and hard verification.

差異化亮點Why Council Forge

驗證是機制，不是口號Validation as a mechanism, not a slogan

關卡守護的工作流Gate-guarded workflow

階段不得任意跳過，合法狀態轉移由 validator 強制，流程可審查、可稽核。Stages can't be skipped; legal transitions are enforced by a validator, making the flow reviewable and auditable.

可稽核的產物Auditable artifacts

研究、計畫、結果全部留痕，工作流可重播且與上下文無關。Research, plans, and results are all on record — the workflow is replayable and context-independent.

內建 Guard 驗證器Built-in guard validators

status 與 contract validator 自動檢查狀態轉移與範圍漂移（task 檔 vs git 變更）。Status and contract validators auto-check state transitions and scope drift (task files vs git changes).

內建紅隊演練Built-in red-team drills

靜態攻擊案例 + 實戰演練 + 重播工作流，並對代理入口檔做 prompt regression 檢查。Static attack cases + live drills + replay, plus prompt-regression checks on agent entry files.

按角色與階段載入Role- & phase-scoped loading

代理不一次載入整套文件，依角色與階段按需載入，token 用量更低更可預測。Agents don't load the whole doc set — context is loaded by role and phase, keeping token usage low and predictable.

住在 repo，不鎖平台Lives in the repo, no lock-in

純文件 + CI 的工作流層，可直接套用到既有 repository，無需採用大型平台。A docs + CI workflow layer you can drop into an existing repository — no platform adoption required.
